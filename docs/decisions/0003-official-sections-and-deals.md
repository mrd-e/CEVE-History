# 0003：天书、正史与折扣是平级板块

- 状态：已采纳
- 日期：2026-11-25（UTC）
- 范围：导航、官方内容集合、网址、折扣数据与展示
- 关联：[网站设计](../site-design.md)、[官方内容指令](../../src/news/AGENTS.md)、[共享呈现](0004-shared-navigation-and-reading.md)

## 背景

官方新闻、世界观文章和历年促销对照服务不同的阅读目的。早期“天书下设宇宙与日历”的方案，以及活动横条、逐年泳道布局，已经不能代表当前结构。源码目录的嵌套也不等于网站导航的层级。

## 决策

- 导航以 `src/_data/sections.js` 为唯一登记：列传、战役、军团与天书、正史、折扣六板块平级，分为玩家野史与官方内容两组。
- 天书使用 `/news/`，正史使用 `/lore/`，折扣使用 `/deals/`。正史文件仍可放在 `src/news/lore/`，折扣清单仍放在 `src/news/calendar.json`；不得因文件名含 `news` 或 `calendar` 恢复旧的子分区网址。
- 天书是官方新闻的中文照录或翻译，不加入原创锐评；正史按官方栏目编排世界观文章，只在点名时逐篇收录，不因存在 RSS 自动扩成批量翻译。已有天书文章可用 `lore: true` 交叉列入正史，保留原文档与原网址，不复制第二篇正文。
- 折扣是一份本站编写的结构化清单，独立于是否已有天书文章。起止时间只维护在清单，公告详情反查关联；商品与价值档由 `scripts/news-calendar.mjs` 统一推导，模板和浏览器不另写分档算法。
- 折扣用于跨年观察商城优惠规律，不恢复为游戏内活动日历。主视图为十二张月份对比卡；“正在进行／即将开始”不受历史筛选影响。分类、起点、支付渠道、赠送与买赠的细则只在官方内容指令和网站设计维护。
- 外部表格用于查线索与核对，不能直接替代逐条整理的清单；清单不新增来源、备注或预测字段。官方译文中的商城名称不能替代实际货币与购买渠道判断。

## 理由与取舍

保留共享工具和数据目录，同时让读者按内容目的直达板块。独立清单可以容纳没有译文的历史折扣；统一推导避免同一优惠在不同页面被判成不同档。接受少量保留旧命名的内部文件，避免只为名称一致迁移路径。

## 旧方案的适用边界

`openspec/changes/news-lore-and-calendar/` 的早期设计与规格仍含宇宙子页签、`/news/calendar/`、活动泳道和旧起点。这些冲突部分不作为恢复旧行为的依据；采用本 ADR 与当前专题规范。该草稿其余需求须逐项核对，不能据此声称整个 OpenSpec 变更已经同步或归档。

## 验收

- 核对 `sections.js`、Eleventy 集合、页面 permalink、导航高亮与站内链接一致。
- 相关回归入口：`scripts/news-lore.test.mjs`、`scripts/news-calendar.test.mjs`、`scripts/news.test.mjs`；数据使用 `npm run news:check`。
- 改折扣交互时核对跨年对齐、筛选不改变顶部状态区，以及无 JavaScript 仍可读；不以旧泳道测试反过来要求回退页面。
