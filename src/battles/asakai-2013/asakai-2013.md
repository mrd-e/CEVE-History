如果不是那位泰坦飞行员在开桥前一瞬间点错了按钮，暗涌之域那座普通的小型旧式玩家建筑，本来连上地方新闻都不够格。偏偏这位 CFC 驾驶员原本想把大部队投送去别人的小规模交火凑热闹，结果手一滑，把自己连着一条勒维亚坦级泰坦孤零零送进了低安星系艾萨凯——直接砸在 PL 舰队的眼皮底下。

PL 的诱导小号当场亮灯，CFC 紧急广播摇人救驾，HBC 一边也火速拉响全军集结。十五分钟内本地人数就冲上两千七百五十四，时间膨胀被硬生生压到百分之十，事先压根没做强化的节点很快被塞成慢动作幻灯片，一场谁也没写进作战计划的大会战就此开了席。CCP 事后从服务器日志结出七千一百七十亿 ISK 的账单：三条泰坦、七条超级航母、五十三条无畏、三十六条航母外加八百多艘常规舰，几乎全落在赶来救泰坦的 CFC 头上。

## 一次误跳点亮诱导，低安集结十五分钟拉满

这场仗的开局荒诞得像场事故报告。起初只因暗涌之域一座旧式玩家建筑刚退出强化周期，CFC 内部情报既没摸清当地势力与 PL 之间早有旧交，行动沟通又只捂在小圈子里；等到 `Dabigredboat` 误跳进艾萨凯发现四周全是对面的枪口，第一反应便只能向全 CFC 广播求援。

可救援消息在频道里刚转两圈，另一头的 TEST 与 PL 已经按着诱导坐标排好了接盘的队列，HBC 这边的舰队越聚越密，一场原本为了止损的抢救行动瞬间变成了单方面的围猎局。

::: 高潮 舍不得九百亿泰坦，最后交了七千亿学费
CFC 领袖[米塔尼](../../p/443630591/)战后亲自写了篇《艾萨凯大崩溃》（*The Asakai Meltdown*）复盘，把这一夜拆成了一串连环失误：低安星域开不了拦截泡，想抓对面的超旗必须靠重拦，CFC 却偏偏没备够重拦；前方敌军越聚越多的情报一条条传回来，救援部队还是没及时踩刹车，一船一船往里填。

米塔尼事后算过一笔最扎心的账：当初干脆咬牙把那条误跳的泰坦直接扔掉，损失不过九百亿；舍不得这九百亿，最后公开记录上硬生生挂出一条拉格纳洛克、一条勒维亚坦、一条神使，外加六条超级航母。沉没成本这门课，CFC 交了七千亿学费，讲义还是领袖自己执笔写的。
:::

## 百分之十膨胀里排队枪毙，超旗成了全服签到表

两千多人挤进一个未强化的低安节点后，所有动作都被百分之十的时间膨胀拉长成了慢放。由 TEST 领头、PL 唱主角的 HBC 大队稳稳占住场面，近两千名角色整场只掉了一条夜神级超航；对面一千出头的 CFC 援军则陷在没重拦、没后路、走不掉的泥潭里，眼睁睁看着自家超旗与泰坦挨个被集火融化。连一百三十九名第三方散户也闻着味摸进艾萨凯外圈，趁着两边大船动弹不得，在百余条零碎击杀里顺手捡些便宜。

::: 高潮 一千零七十人围殴万古，连新手船都赶得上排队
UTC 五点半，CFC 一条万古级超级航母（Mr McNasty）在围攻里缓缓炸裂，击杀单上挂着的攻击者竟然多达一千零七十人——几乎等于全场三分之一的角色同时冲着这一艘船开了火；一个钟头后，RAZOR 的神使级泰坦也跟着倒下，攻击者足有九百五十四人，最后一刀让 Black Legion. 稳稳补进囊中。

在百分之十的时间膨胀里，这么多人能从容不迫地挤上同一张击杀单，只说明那条大船在原地趴得实在太久，久到连刚出站的新手船都来得及慢悠悠飞过去排队点上一炮。CFC 这边的超旗来时是救火援军，走时变成了一张张写满陌生人名字的公共签到表。
:::

## 成立不到一年的盘古，拿着新手船挤进历史中心

在 HBC 浩浩荡荡的国际大队里，成立还不到一年的华人组织盘古联盟也跟着把自己的名字挤进了艾萨凯的历史记录。虽然公开战报上盘古一共只出现十六个角色，[行星之光](../../corps/lotm/)与[雷爪舰队](../../corps/tcf/)的老兵们却半点没在这么大的场面上怯场——船不够大没关系，腿脚够快就行。

::: 高潮 四位盘古元老合凑零头船价，硬在神使名单上占座
盘古这一夜最体面的战果，是把四张熟悉的中文社区招牌齐刷刷钉进了 RAZOR 那条九百五十四人围殴的神使级泰坦击杀单：出门先看通讯录再看总览的盘古建盟外交官[Wind](../../p/1901851878/)开着共和舰队火尾鸡贴上了脸，平时管着生产租地团 Cappuccino Cafe 账房、号称只算地租的[肉丝](../../p/224870524/)切出隐轰蝎尾怪来补刀，日后以在星门堵路闻名的[水哥](../../p/91282906/)早在前一个小时就用同一条短剑截击舰挤进了万古超航一千零七十人的大单，而当年在[雷爪舰队](../../corps/tcf/)坐镇的[D哥哥](../../p/690534767/)最绝——他开的是一条伊毕斯号，也就是新手出生白送的那条护卫舰。

四个盘古元老凑在一起，四条船加起来还不够泰坦一门炮贵，名字却稳稳和 PL、TEST 的老炮们并排挂在同一张泰坦账单上。盘古当晚自己只赔了五条小船：两条维拉托尔号、一条伊毕斯号、一条猎犬和一条纳美西斯，在全场七千亿的大账里连个零头都算不上。拿新手船去签泰坦，赔的也是新手船，这笔买卖，全宇宙没几家做得比盘古划算。
:::

## 散场不写自己开什么船，四年后再发史料视频

艾萨凯的炮声最终在凌晨开打后约八个小时渐渐散去，HBC 带着悬殊到近乎十比一的战损比满意散场，CFC 则只能靠米塔尼的复盘专栏来消化“为什么没早点止损”。至于在华人社区里，这场没有战略计时的意外混战之所以多年后仍被津津乐道，还得靠四年后那位新手船驾驶员自己端出来的视频。

::: 高潮 四年后上传十八分钟老录像，只字不提自己开着伊毕斯
2017 年，早已带着兄弟们打过不知多少场硬仗的[D哥哥](../../p/690534767/)在 B 站上传了一段十八分钟的[《Battle of Asakai》](https://www.bilibili.com/video/BV1hx411H7mc/)，简介开头先正经定了个调：“这是一个纪念意义的老视频。”他在文案里工工整整从 Goons 转移泰坦被抓讲起，写到 PL 的诱导小号亮灯、“然后整个宇宙都知道这里发生了啥”、十五分钟集结两千七百人，末尾还仔细列出两边的旗舰损失——CFC 三条泰坦、四十四条无畏、五艘大航、二十九艘航母，HBC 只有一条大航、六条无畏和十条航母。

当年开着系统白送的伊毕斯号去签泰坦的人，四年后把整场战斗当成经典史料端上了 B 站，口吻像极了一名冷静客观的战地记者——只是整篇长长的简介翻到底，偏偏没提自己那天在场上开的是哪一条船。
:::

::: 评
艾萨凯这场仗没有战略，没有计时，只有一个按错的跳跃和一群不肯认赔的人。CFC 用七千亿证明了“来都来了”有多贵；盘古则证明了另一件事：只要来得及，新手船也能在历史上签个名。
:::
