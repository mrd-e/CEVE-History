伊格诺伊顿这桌不到一小时的短局，算得上低安海盗圈最不讲道理的烧钱速度：格子里总共只挤了五百六十九个角色，人数连常规千人会战的一半都凑不齐，天还没透亮，双方的无畏舰却已经硬生生把总账轰穿了一万零一百七十一亿。一边是 Snuffed Out 连同盟友 INIT、[AVDOT](../../corps/avdot/) 与 [天降](../../corps/the-skies-descend/) 等两百九十三人，另一边是 Deepwater Hooligans（BIGAB）、Sedition 与 [Family Guy](../../corps/familyguy/) 等两百人的无畏主力群；谁也没多讲废话，诱导一亮就只拿几亿几十亿的船体对填。

## 一小时短局开火，血鸦一百三十六亿先响第一声脆响

世界时凌晨一点三十四分过后，双方前锋才刚把阵形挪上位置，Deepwater 一侧就先交出一份让人倒吸凉气的开局清单：交火仅仅不到一分钟（一点三十五分二十二秒），BIGAB 阵里一艘估值高达 **一百三十六点二亿的血鸦** 仅仅被五名对手集火便提前炸成烟花（最后一记重手由一条莫洛级拿下最高伤害）。

大船刚一撕开口子，两边的老熟人各自站定了最拿手的座位。原本在低安人潮里并不算庞大的华人团体这回恰恰分驻在交战两头：BIGAB 这头来了九名 [Family Guy](../../corps/familyguy/) 飞行员跟着接战；对面 Snuffed Out 旗下除了八名[天降](../../corps/the-skies-descend/)成员之外，整整二十四名 [AVDOT](../../corps/avdot/) 成员跟着旗舰阵直接顶上了第一线。

::: 高潮 儒将塔玛不守门，巴盖斯与泽尼塔在无畏堆里两头兼顾
平日里蹲在加达里与黑渊咽喉塔玛星门前、用粉绿富文本给自己贴上“AVDOT首席智将”和《铁甲小宝》蜻蜓队长誓言的[绅士](../../p/2081750081/)，这一夜总算把看门的那艘警惕级停回了仓库，亲自开进一艘马克瑞级跟着 Snuff 主力左右压阵，不到一小时就稳稳蹭下四十九次击杀；而作为 Infinity Avenger 掌门人的 [Sayler](../../p/2113271910/) 更不吝惜多开手速——他先用主号架着一艘巴盖斯级在大船堆外围连续集火收下十七杀，与此同时早就把小号 `BalmungS` 塞进泽尼塔级压入正战重火区，两点未到的一点五十七分五十四秒便精准轰穿了对手一条七十二点三亿泽尼塔级的最高伤害榜首，主号在战列圈里抓稳距离，副号直接钻进无畏泥潭啃大肉。
:::

## 泽尼塔与神示级海军型排队点名，两千亿对七千亿

一点四十五分到两点零二分这不到二十分钟，几乎决定了全夜的流血节奏。Deepwater 与 Sedition 尽管靠着满编无畏跟 Snuffed Out 正面互殴、一度连连拆掉对面多条莫洛级海军型与泽尼塔级，可自家核心阵线很快遭遇对面全火力点名——战后一清点，单是 Deepwater 与友军这一边就在一小时里连掉三十二条神示级海军型、三十一条莫洛级海军型、二十六条泽尼塔级、两条使徒级外加十八个高价太空舱，其中一条估值约九十二点九亿的莫洛级海军型更是直接被对面神使级泰坦的末日或重火送上最高伤害名单。

而就在高价值无畏接二连三炸开的当口，双方战报攻击者名单里居然还飘出了神使级、万古级、征服者级等超旗级巨兽的署名——偏偏它们下场抓完伤害后便没再真正滚成超旗对轰，恰好替 B 站上的录像与评论区埋下了现成的笑料。

::: 高潮 对跳泰坦却不对轰，九百亿战果在 B 站引出剧本吐槽
伊格诺伊顿还没彻底打凉，联合署名为 `NoNoOwO`、`舰长雷耶斯`、`少侠LNP` 与 `BeliEVE76` 的视频《【SnuffedOut】Ignoitton-轰一把900b的旗舰》便在当天清晨五点多火速上线，简介干脆利落只写了四个字符的战果对比：“200b：700b”。晚些时候 BeliEVE76 还顺手搬运了一部英文原作录像《对BIGAB使用泰坦吧！》。

评论区里观众的眼光比任何解说都毒：有人盯着片尾感叹“深水吃了这么多次亏，就不能反剧本一次？”，另一头 [W佬](../../p/93331025/) 顶着 `dzkell` 的账号直白调侃起双方在格子里亮出超旗却克制收手的微妙局势——“对跳泰坦，就是不对轰 哈基米 VS 大狗叫”；甚至有玩家把进度条停在 `02:48` 追问那条无畏怎么跑掉了，也有人抱怨装备贴图被遮住，“其实去 zkill 也能找，就是多花点时间，很小气啊”。场上的九千亿火球还没散尽，场下的吐槽先把剧本拆了个底朝天。
:::

## 散场两刻钟余波，大鱼车队老熟人撞进收尾炮口

凌晨两点零五分过后，双方主战无畏群陆续脱离网格，伊格诺伊顿的击杀节奏骤然放慢。正当所有人以为这出五十六分钟的超快无畏秀已经彻底拉下帷幕时，战报尾端未归组余项里却突然蹦出了一个让人会心一笑的第三方名字。

::: 高潮 塔瑟提战神不开大鱼开巨象，散场前在伊格诺伊顿连蛋带车一起交
熟悉[赵建国](../../p/2115652382/)的人都知道他那句“当年进欧服只想安稳刷萨沙怪”的吐槽——结果一路十开大鱼挖矿把 BBC 泰坦招来矿点、简介顶着七条大鱼战损的他，偏偏在这个刚爆了一万亿旗舰残骸的低安星系边缘现了身。两点十四分五十五秒，他名下小号 `zama Jovakko` 驾着一艘估值约五亿七千万的巨象级工业运输舰在伊格诺伊顿被中途拦下撕碎，五十一秒后的两点十五分四十六秒连太空舱也一并送回老家。比起自己角色简介里写的“三选一台词：1、蝼蚁看我如何灭杀你；2、道友你我各不相扰；3、前辈饶命”，这回赶在万亿混战尾声路过交税，大概只来得及按下第三句。
:::

## 两百亿换七百亿的体面账单

两点三十一分，最后一笔余波落地，整份不足一小时、仅有两百二十九条击毁记录的战报正式封账，总额冲到一万零一百七十一亿出头：Snuffed Out 与友军两百九十三人总共付出两千三百九十三点八亿（含关联组织累计约两千五百六十九点一亿），出动八十三人的 INIT 全程竟没留下一笔亏损记录；反观 Deepwater Hooligans 一侧两百人共吞下七千二百四十五点六亿（加计友军约七千五百八十二点三亿），光 BIGAB 本盟就认账六千二百零七点七亿，Sedition 认了一千零三十七点九亿，单条最高战损记录也留在那艘一百三十六点二亿的血鸦头上。

::: 高潮 一小时破万亿的钱包效率
五百六十九个人打成破万亿级别，放眼全服都是罕见的高消费夜场。Snuff 这边也实打实交了八条莫洛级海军型、八条泽尼塔级、七条神示级海军型和四条使徒级，并非毫无痛痒；只是隔壁 Deepwater 与 Sedition 那张几乎翻了三倍厚的账单摆在同一行，立刻就把两百多亿衬出了一份低安老海盗独有的体面差额——仗打到这份上，人数只负责在战报顶端站台，无畏价格才负责决定散场谁先叹气。
:::

::: 评
伊格诺伊顿这一仗，从两点多亮诱导到收摊还不到一个小时，连让观众酝酿情绪的前戏都省了：先秒一只一百三十六亿的血鸦热场，接着两边近百条无畏排着队进坟，末尾还顺带把路过的巨象工业船收进尾款。

Snuffed Out 自己赔了近两千四百亿不算轻，可架不住 Deepwater 与 Sedition 直接烧出七千多亿替整张桌面封了顶。战报很快合上，录像也很快在 B 站写出了“200b：700b”的战绩碑——低安的体面话不用说太满，把对方三倍厚的残骸列表贴在自己账单旁边，比什么口号都管用。
:::
