秋风刚起，绝地星域在 8F-TK3 把积攒多时的领地旧账一次烧成了约一点八一四万亿的漫天残骸。一边是[创世](../../corps/chuangshi/)、龙焰（Dracarys.）、Wings Freedom 带着三十多支华人与友军分队，九百四十七名角色列阵迎敌；另一边是 WOMP 连同盟友 INIT 及[宇宙流浪者](../../corps/wanderers/)等七百五十三名飞行员。两个多小时的主战交锋后，WOMP 本盟独吞约一点一一七万亿的巨额亏损，占去了对面大半张账本。

## 领地翻桌与百条误差

这场会战的起火点早在战后被当事人吵成了两本账。Wings 外交复盘把导火索算到 OnlyFleets 解散后的绝地领土归属、两座新落下的阿斯特拉豪斯以及被打掉的塔塔拉身上，指称 WOMP 领头人 Rexan 起初答应谈判割让 T8T 一带，随后反悔失联；Rexan 当即在同帖反驳称自己从未给出承诺，只说要带回联盟内部商议，反而批评 Wings 胃口太大，甚至要牺牲 NAVY 与 DECOY 两家的地盘。一个说对方说话不算数，一个说对方张嘴就要邻居的家，外交议事桌谈到十月初彻底谈崩，双方干脆直接约到 8F-TK3 用旗舰算数。

真正把两边全员拖下水的还有一份要命的情报误差。Wings 自称早早看穿 WOMP 对自家时区旗舰规模颇有自信，于是故意摆好架势诱敌加码；而 Rexan 战后也坦白承认侦察出了大岔子——龙焰实到战场的无畏比侦察事先汇报的数字多出约一百条。

::: 高潮 外交桌搬上无畏擂台
真正把两边拖下水的，是战报里几乎一边倒的人海与后备箱差距：[创世](../../corps/chuangshi/) 联合龙焰（Dracarys.）和 Wings Freedom 把半个绝地华人战备群全拉进了集结频道，[纱布](../../p/96262961/)、[低调](../../p/2115988005/)、[小可](../../p/2120938298/)、[漆黑](../../p/2121165138/)、[黑米](../../p/2117153585/) 与 [图万·奥斯神殿](../../corps/tuvan/) 的 [萨格](../../p/2122554826/) 六人全坐在指挥位上排兵布阵，背后除了 [兔飞](../../corps/tufei/)、[宽带山](../../corps/kds/) 与 [Dusk](../../corps/dusk/) 等龙焰主力外，连隔壁凛冬旗下的三家主力都悄悄派出了援兵；反观 WOMP 的战列线旁，尽管 [黑暗闪耀](../../p/1869573834/) 带着两百多名 INIT 成员以及 [宇宙流浪者](../../corps/wanderers/)、[帝皇之镰](../../corps/scythes/) 等旧友助阵，对面的旗舰池深度却早已远远超出了己方侦察预案。那份建立在漏算上的安全感，只撑到第一声诱导亮起便宣告作废。
:::

## 五点一刻接火与百艘无畏露底

傍晚十七时一刻过后，双方前锋与第一批旗舰刚进场便擦出火星。[初梦](../../p/2116299695/)的使徒级在十七点二十二分率先拿下约八十点一亿的对手击杀最高伤害，[烈冰玄武](../../p/2120988347/)随即用凤凰级于十七点二十五分轰出约四十四点六亿的最高伤害；WOMP 火力很快回敬过去，十七点四十一分[萝卜](../../p/2122186397/)先损失一条约六十二点二亿的莫洛级海军型，十七点四十六分[七七](../../p/2121733921/)也交掉约六十一点三亿的莫洛级海军型，所幸小号开出的泽尼塔级连拿三个伤害榜首把输出追了回来。

正战刚进入交换比最惨烈的阶段，[一剑](../../p/2119595519/)于十七点四十四分驾驶无畏抢下约四十七亿的绝念级伤害榜首，转眼自己在格子里部署的移动牵引装置与移动诱导抑制器也被顺手拆了个干净，一笔五亿六千万加上一笔六千万直接写进了配件账单。等到后排成群无畏真正落地展开，WOMP 指挥部很快意识到侦察情报里的数字出了致命窟窿。

::: 高潮 少算的一百条龙焰无畏
藏在阴影里多出来的那约一百条龙焰无畏一齐开火，彻底把天平压向了一边：平时多开狂刷击杀的 [兔斯基](../../p/2112441816/) 用小号神示级海军型收下六十七杀，[陌然](../../p/2114453889/)、 [沐雨](../../p/2123483807/) 驾着泽尼塔级各扫过五十余个目标，[多米](../../p/2118339639/) 的凤凰级海军型紧随其后收下五十七杀；连一边盯着战场宏观调度的 [DA](../../p/2114273804/) 与 [漆黑](../../p/2121165138/)，都抽空多开了神示级海军型进无畏阵里凑了三四十记签名。点杀最毒的还要数多开老手 [探归](../../p/2114368430/)（三开泽尼塔级外加狂暴级舰队型，直接轰穿对手一条六十七点二亿大船）、[萨格](../../p/2122554826/)（单点敲掉六十六点八亿的莫洛级海军型）、[兔总](../../p/91874271/)（拿走约六十三点八亿伤害榜首）与双开泽尼塔、神示级海军型齐发的 [随风](../../p/2115325695/)。上方无畏把 WOMP 旗舰死死钉在原地，下方常规收割队则像闻到血味的鲨群扑向马克瑞阵线——[机械神甫](../../p/2121980797/) 在混战里三度抢下马克瑞级最高伤害，[两千](../../p/2114348755/) 与 [死枪](../../p/2114324057/) 开着渎圣级重拦把泡泡牢牢扣在对方撤退点上，[D哥哥](../../p/690534767/)、[红名](../../p/2114820390/) 与双开的 [狂天](../../p/2116350757/) 则在外圈来回点射，逼得整张绝地战场只剩下同一边的一面倒火力。
:::

## 穿梭机八连炸与两翼反扯

重火对轰没让任何人白白站在场里看戏，到了十八时前后，双方开始陆续交出昂贵旗舰与意想不到的奇葩战损。十七点五十二分，[飞飞](../../p/2116369488/)的泽尼塔级刚以约八十点三亿拿下当日单场旗舰榜首级别的伤害表现，仅仅两分钟后的十七点五十四分，他自己那条约五十八点一亿的泽尼塔级便被打回船坞（后来他的巴戈龙级也在十八点四十二分交代在场）；十七点五十九分，用曙光女神级辅助出二十一杀的[珅](../../p/2118018631/)也丢了一条约四十点三亿的莫洛级。

::: 高潮 神示双换与八条艾玛穿梭机
最离奇的一串时间线落在十八点初段的混战里：[梁天](../../p/96506815/)主号神示级稳稳拿了六十三杀，小号 Uber Eat 先于十八点零三分四十秒轰下一条约六十一点三亿神示级海军型的最高伤害，不到五分钟后的十八点零八分三十五秒，自己那条约六十七点三亿的泽尼塔级便被集火撕碎；同一时段更令人哭笑不得的是[山之内花音](../../p/2123019905/)——他的小号先是用泽尼塔级连拿三个伤害榜首，十八点零七分三十五秒交出一条约六十九点八亿的泽尼塔级，紧接着十八点十八分二十九秒至十八点二十分整短短一分半内，他在战场上竟然一口气连丢八艘艾玛穿梭机，硬是把严肃的超旗战战报刷出了一串穿梭机队列。稍晚些，指挥位上的[纱布](../../p/96262961/)在十八点二十四分失去一艘坐镇战局的指挥座舰后，仍靠另一头的无畏小号刷完三十七杀，[低调](../../p/2115988005/)丢了短剑级，[初梦](../../p/2116299695/)的神示级（约四十四点二亿）与[烈冰玄武](../../p/2120988347/)的凤凰级（约三十点七亿）也在十八点四十五分之后先后阵亡。
:::

同一时间线的外围又是另一张面孔。在 WOMP 主阵被百艘新增无畏啃得满地找牙之际，站在同一边的 INIT 反倒用常规游击队打出了截然不同的性价比。

::: 高潮 黑暗闪耀助阵与账单温差
[黑暗闪耀](../../p/1869573834/)带着 INIT 两百三十六名角色进场支援 WOMP，整场打下来本盟损失仅约三十四点三亿。外围队伍里，浩与[花花](../../p/2121993705/)、[小黄人](../../p/2119217172/)都开了鱼鹰级海军型拉扯阵线——其中小黄人三开操作，主号丢了天梯级，两个鱼鹰级海军型小号一个负责交船、另一个狂揽五十杀并六次登顶最高伤害，花花则掉了一条约六千万的鱼鹰级海军型；[天鹰](../../p/2120306116/)也在外圈丢掉一艘斯威普级。另一头的创世常规与小船群里，[小洋](../../p/2114834014/)开狂暴级舰队型、[舵主](../../p/91254848/)开台风级、[成风](../../p/2119752265/)双操巴戈龙级与曙光女神级跟紧推进，[zrxz](../../p/2122520286/)（厄里斯级）、[2gg](../../p/2119781938/)（飞燕级）与连交促进级、两艘鹳鸟级及剑齿虎级的[小妖](../../p/2112603797/)不断替大船补拦拆点。同一边打完一场仗，WOMP 成批无畏替侦察误差买单，INIT 却只留下一本薄得多的零头。
:::

## 收账人自付船钱与“再来”

十九点二十六分，8F-TK3 延续两个多小时的会战终于归于寂静。战报统计一共记录了一千一百六十七次击毁、约一点八一四万亿总损：WOMP 及友军七百五十三人合计丢掉约一点二二四万亿，其中光 WOMP 本盟三百七十三人就认下了约一点一一七万亿、最贵单条损失达约一百二十八点四亿；而占优的创世、龙焰及友军九百四十七人也并非毫发无伤，全阵线合计吞下约五百五十一点五七亿损失。

::: 高潮 收账的人也得掏船
赢家账面虽然漂亮得足以摆上外交谈判桌，可真要各自回站结算，龙焰本盟约一千三百四十八点七亿、Wings Freedom 约一千零九十四点五亿的账单，一条条全是真金白银：[初梦](../../p/2116299695/)的四十四点二亿神示级、[飞飞](../../p/2116369488/)的五十八点一亿泽尼塔级加上巴戈龙级、[萝卜](../../p/2122186397/)的六十二点二亿莫洛级海军型，再加上[兔斯基](../../p/2112441816/)从台风级一路掉到小船与太空舱的杂项战损，庆功词再热闹也抵扣不了个人机库里的缺口。对面的 Rexan 面对本盟超过一万一千亿的坑同样没打算低头——他承认侦察少报了一百条无畏是事实，却依然替手下指挥官接战的决定辩护，坚称情报哪怕不完美也必须出手，绝不能因为怕输就不出门，并在长帖结尾干脆地丢下一句“再来”。
:::

::: 评
8F-TK3 打完，舆论场上很快摆出两份截然不同的胜负账：Wings 一侧把伏击成功与敌方万亿损失摆到最前头，试图替 T8T、NAVY、DECOY 与新下的阿斯特拉豪斯、塔塔拉争一个外交身位；WOMP 的 Rexan 则宁可承认百条龙焰无畏的侦察盲区，也不肯认怂退缩，甩下一句“再来”强撑士气。

只是舆论的嘴可以各说各话，机库的船却不会跟着嘴硬。同站一条战壕里的 INIT 仅仅赔了三十四亿多，WOMP 却实打实把一万一千多亿沉在了绝地格子里；而收下大胜账面的龙焰与 Wings 各自千亿级的船钱照样要自己消化。领地归属还没在嘴仗里划明白，双方倒先把各自的后勤表填满了一整页。
:::
