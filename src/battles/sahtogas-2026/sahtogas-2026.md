保家守城偏把日程先挂上公开频道，结果招来的不只是援军，还有专门挑好日子赴约的拆迁队。一月中旬，围绕 `LongCheng` 首都星城最后一层结构计时，[红名](../../p/2114820390/) 执掌的龙骑团在萨托加斯摆开守城阵势，不仅招来 FRT 诸部与昔日外援 Snuff 助拳，也把曾收留过龙骑主军团的老邻居深水、乃至乘虚进场的帝国系联军一齐引到了门口；整场攻防横跨五个小时，卷入两千二百二十一位驾驶员、留下一千二百一十六条击毁记录，各方合计烧掉约五千六百九十八亿 ISK，守军五十条战斗旗舰硬碰进攻方近乎纯常规外加零星重锤的拆城阵容，最后仍只能眼睁睁看着这座耗去两千二百四十九亿的星城化作地图上的残骸。

## 提前两天放出守城通告，熟人与旧邻兵分三路赴约

战火还没真正点着，日程表已经在中文社区里跑先一步。一月十一日，[Awakeallnight](../../p/2114626303/) 率先放出《大作战预告：1月13日保卫龙骑团首都星城（结构退增强）》，提前四十八小时替自家人把集结窗口标得清清楚楚；可公开频道从不认敌我，两天后结构倒计时一到，门口不仅停满了自己呼来的救兵，也迎来了早早按时上班的各路拆迁大军。

到了十三日午后，萨托加斯星门与星城网格干脆按新伊甸的恩怨分成了三拨人马。守在城下的[银雾龙骑](../../corps/silverfog/)拉上长期并肩的 FRT 友军——从主战的[采星者](../../corps/starchaser/)到赶来驰援的[混沌](../../corps/chaos/)与[伏羲](../../corps/fuxi/)，一并请出 [出其东门](../../p/2120025597/)、[两千](../../p/2114348755/) 与 [阿巴怪](../../p/2119615259/) 坐镇指挥位穿插调度（[两千](../../p/2114348755/) 在拉扯里先后赔掉了三艘座舰）；Snuff 及其关联华人分队 [AVDOT](../../corps/avdot/) 亦到场替龙骑护航，[Sayler](../../p/2113271910/) 在主攻阶段前一路控麦撑到十四点十二分，[零落](../../p/2115593581/) 与 [Alknight Dong](../../p/2113059348/) 则顶在 `鹏鲲级` 战列线上，携 [少侠](../../p/2118354268/)、[小沙狐](../../p/96137114/) 死守外围。令人唏嘘的是墙外阵势：低安昔日收留过红名主军团的老东家深水这回竟站在了拆城一边，低安的交情从不附带永久保修，一转脸便和 Goonswarm、Dracarys 并肩把炮口架上了城门；[小洋](../../p/2114834014/)、[小可](../../p/2120938298/)、[多米](../../p/2118339639/)、[凯撒](../../p/96254294/)、[暗枪](../../p/2122496778/) 与 [北暮](../../p/2121410019/) 轮番接管进攻方多条指挥频道，而老牌战团 INIT 则拉着[帝皇之镰](../../corps/scythes/) 里的 [老黑](../../p/2121401697/) 与 [小G](../../p/2114069885/) 独悬第三方，谁顺手就揍谁。

::: 高潮 招新官双号折戟泽尼塔，电阻无畏突击留下第一视角
守城打到十四时半，龙头还没压住外围拆迁线，自家骨干的旗舰先在集火下冒起了浓烟。以在贴吧嘴硬出名的龙骑招新官[烈冰玄武](../../p/2120988347/)这回没有只动键盘，他双开主号连着小号一同进场，主号连续交出两只太空舱，驾驶 `泽尼塔级` 的小号更在十四点四十三分于五百七十一人围射下爆出一张[六十八点九亿的亏损邮件](https://zkillboard.com/kill/132613031/)——嘴上守着大门的管事真把身家推到了城外，而且家虽在当天赔掉，他整个一月的杀敌账却逆势冲上了三千亿的生涯新高。就在他爆船前不到七分钟，同在守方护阵的[抵抗之狐](../../corps/fox/)成员[兔斯基](../../p/2112441816/)也在十四点三十六分折损一条六十四点一亿的[莫洛级海军型](https://zkillboard.com/kill/132612894/)兼太空舱，战后该团顺势将这段冲阵剪成[《FOX图尔无畏小分队突击——无畏视角》](https://www.bilibili.com/video/BV1kArjBSEYM/)传上B站，算把自家无畏群死磕星城门前的画面钉在了公开频道里。
:::

## 五开血鸦当场沉没，混战中三家都在算各自的账

虽然龙头与 FRT 一侧前后压出了五十条战斗旗舰（光无畏就送进网格四十三条，最后折损三十三条并搭进五条战力辅助舰），进攻方整场却只掏出过一条长矛无畏舰，其余全靠重巡、战列与高速小船在结构计时边缘轮番磨血。低潮并不代表省钱，双方在星城炮火和反跳泡泡里来回换血，连五开压阵的氪金好手也没躲过集火榜首。

::: 高潮 七七五开痛失百亿血鸦，红楼与帝国舰队抢位拆门
帝国、深水这头看似没拉整编无畏海进场，可单舰掉起价钱来照样让人肉痛：十四点三十八分三十九秒，挂名 [YSS](../../corps/yss/) 出勤的 [七七](../../p/2121733921/) 同时拖着五个账号在战场周边调度，其中一员坐镇长矛无畏 `血鸦级`，刚在网格亮炮没多久便遭两百七十一名敌手合力按住，轰出一张[一百三十九亿的击杀邮件](https://zkillboard.com/kill/132612929/)——这也是整场萨托加斯攻防单船最高的一笔账单，此外[小洋](../../p/2114834014/) 的小号也在换防里交掉一条三点五亿座舰。可帝国攻势并没有被这一发打慢半拍：[红楼](../../corps/honglou/) 的 [兔兔](../../p/2123050360/) 双开驾着 `死亡漩涡级` 卡住火力点，同在阵中的 [钟离尘风](../../p/2119086999/)（开出 `忏悔者级`）、[Ghost与加里](../../p/2120624679/)（同样操控 `死亡漩涡级`）、[橙子](../../p/2113753822/)（战后还剪出了混剪[《萨托佳斯千人会战超燃混剪》](https://www.bilibili.com/video/BV1gbkwB8EZV/)）、三开的[侃侃熊](../../p/96646658/)、连续交船三次的 [白魔爪骑士团](../../corps/kzu/) 成员[声望哥](../../p/2120632368/) 以及后来上传[《帝国系开拓低安内容区首秀》](https://www.bilibili.com/video/BV1XzrLBKEoz/)的[一捆烂胶带](../../p/2114508645/)，一步步把防线推回星城外墙；就连始终只赔了二十二点一亿的第三方 INIT 阵营里，[老黑](../../p/2121401697/) 与 [小G](../../p/2114069885/) 照样跟着游猎捡漏，硬生生替房主在门外又添一桌要提防的客人。
:::

## 星城咽气前七分钟，昔日金主驾奇美拉同赴残局

推进下午三点半，守方旗舰序列大半化作残骸，星城结构血条跌破最后一道红线。一千一百一十五名进攻方船员把炮口全部锁上星城外壳，[飞飞](../../p/2116369488/) 主号开着 `渎圣级`、小号 `tuzifei001` 驾着零伤害的 `永灭级` 双双挂名榜单，连 [DA](../../p/2114273804/)、[非物](../../p/2120847133/)、[乔布](../../p/2121450438/) 与深水小号出身的 [汉堡](../../p/2117195144/)（其本人另赔出一艘近四亿舰船）也在乱军里各记上一笔。偏偏在星城最后咽气的节骨眼上，网格里开进来一位让战后复盘谁也绕不过去的老熟人。

::: 高潮 穿回采星战袍守旧城，奥托赶在爆炸前交出奇美拉
要说龙骑首都倒得最具宿命感的一幕，发生在世界时十五点三十三分五十七秒——距离星城彻底爆裂只差七分二十五秒。[奥托](../../p/97259613/)，这位早年替龙骑团牵头筹款锚下首都、后来却与管理层闹翻退团的前核心，早在前一年九月便已转回 FRT 旗下的[采星者](../../corps/starchaser/)；可真到这座旧城命悬一线的正午，他还是跟着救援舰队回到了萨托加斯守城一侧，整场交火足足留下十四条损失记录，临近收官更驾着一艘八十五点七亿的[奇美拉级](https://zkillboard.com/kill/132614229/)航母在五百四十三人炮火下殉城。紧接着在十五点四十一分二十二秒，`LongCheng` 化作[那张两千二百四十九亿的星城击杀邮件](https://zkillboard.com/kill/132614377/)。极具反差的是，身在 FRT [行星之光](../../corps/lotm/) 守城阵营里的 [墨菲](../../p/2117806220/) 战后却端出一部直白打脸的英文标题影片[《萨托加斯 Fraternity gets OBLITERATED》](https://www.bilibili.com/video/BV1azrmB4EmD/)，把自家人被全歼的字眼直接挂上了封面。
:::

## 录像和贴吧同时开张，房子没了半年还在互相拆台

接近十七点整，萨托加斯网格里零散清场完毕，整场大战以约五千六百九十八亿的总损定格。然而对龙骑团来说，建筑爆裂反而只是舆论战的哨声：不到一天工夫，视频区和贴吧便接过接力棒，把同一座星城的来龙去脉拆成了两套截然相反的版本。

::: 高潮 次日交上全程录像，半年周年文案被一句“守住了吗”破防
战后第二天，发起战前预告的 [Awakeallnight](../../p/2114626303/) 就与合作者把[《【EVE】中字解说：萨托加斯千人会战（全程录像）》](https://www.bilibili.com/video/BV1UXr7BNE4d/) 端上了 B 站，一口气冲出一万五千多次播放——预告里的首都虽然真没守住，可承诺过玩家的千人会战倒是准时交付得一分不少。更有戏剧性的是半年后的六月二十七日，他又发布[《纪念首都萨托加斯之战（龙骑团星城下锚一周年）》](https://www.bilibili.com/video/BV1zvTA6hEfQ/)，文案高歌“面对数倍于己的敌军，龙骑团率先迎敌，混沌舰队奋力驰援”，试图替败仗守住体面；结果评论区最高赞冷不丁飘出一句“守住了吗”，一刀把满篇壮烈重新拉回一月十三日下午那张星城残骸邮件。
:::

::: 高潮 贴吧当夜翻出负七百八十亿旧账，同一块招牌两家各敲各的锣
视频区还在讨论体面，贴吧的刀早已捅向了肺管子。[奥托](../../p/97259613/) 趁热写出[长篇回忆帖](https://tieba.baidu.com/p/10397869272)，追忆星城最初起名 `UNITY`、后改叫 `LongCheng` 的筹建过程，顺带公开指责 [红名](../../p/2114820390/) 懒政摆烂、拢权不干实事，把败因往管理头上一推；当天招新官 [烈冰玄武](../../p/2120988347/) 立马贴出[《三句话，奥托为什么被踢出龙骑？》](https://tieba.baidu.com/p/10398160816) 迎面反咬，直指奥托此前 RMT 订购二十条泽尼塔致使红名钱包背上负七百八十亿亏空、提案高安挖矿洗钱遭拒后图谋政变。护盾早在十五点四十一分炸个干净，团里的信任倒还能照着一百层往深里削——金主记的是“我拉钱立起来的家”，管事记的是“你给家里引来的祸”，一座塌掉的首都就此变成了两家公开翻旧账的擂台。
:::

::: 评
提前两天把首都星城结构时间贴上预告，换作谁都像把约战请柬亲自塞到拆迁队手里；更讽刺的是，昔日拉着大家集资建城的金主，离开后再穿回老盟战袍替旧城送上一条奇美拉，而城破后的战报与贴吧长帖又把“负七百八十亿”和“守住了吗”焊成了永久注释。房子只活了半年，可围绕房子铺开的预告、周年纪念和连环撕破脸，比任何一座星城都更加结实耐烧。
