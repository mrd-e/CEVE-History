新堡的上线计时直接摆进对手星城的客厅同一格，连星门过路也要先交加载卡顿的过路费——六月初发生在因斯姆尔 `HB-1NJ` 与 `EFM-C4` 的这轮跨夜攻防，把四千五百名去重驾驶员拉成两条互补战线：一边是蜜蜂硬着头皮站在 PH 家门前立铁壁、硬扛九十分钟把堡安顿下来，另一边是提前守好门前门后的截援伏击战，两场合计丢下两千四百二十三条残骸、逾四千六百九十五亿 ISK（其中帝国一侧约一千三百九十亿，PH 及友军承担逾三千三百零四亿）。

## 星城眼皮下先立铁壁，隔着一千五百公里对望四十五分钟

::: 高潮 对峙四十五分钟拉开千亿家门攻防，Periodictpr 与帝国五十五杀猛将先摆阵脚
六月四日傍晚世界时十八点零三分，蜜蜂前一日悄悄锚在 `HB-1NJ` 的新铁壁走完二十四小时无敌期，正式迎来生死攸关的上线计时。这座堡的位置挑得极为挑衅——就在 `PH` 主基地星城同一个太空网格里，两者相隔不过约一千五百公里。

帝国与友军约一千九百多名驾驶员早早占满铁壁周边：[一捆烂胶带](../../p/2114508645/)（在 [星华](../../corps/sing-hua/) `兀鹫级` 队列打满五十五条战报记录）、[非物](../../p/2120847133/)、[一八](../../p/2119472256/) 与 [暗枪](../../p/2122496778/) 齐驾 `兀鹫级`，[德玛](../../p/2115768319/) 领着 [红楼](../../corps/honglou/) 驾驶 `猛鲑级海军型`，龙焰侧 [SummerHall](../../corps/summerhall/) 的 [木木三](../../p/2114825720/) 也在结尾交出一艘近六亿的 `兀鹫级` 和太空舱，而 Goonswarm 盟主 [阿舍](../../p/1687651723/) 更亲自驾驶 `净化级` 兼 `鹰身女妖级` 上阵并留过船损与蛋壳；对面的 [PH](../../corps/pp/) 阵地上，约一千四百多名守军由 `Profane Proverb` 的 [PeriodicTpr](../../p/2118325902/) 坐镇指挥位统筹，带着老班底 [黑米](../../p/2117153585/)（交出一艘五点二亿 `兀鹫级`）、[多米](../../p/2118339639/)、[超绝](../../p/2122271073/)（同样折损一条五点二亿 `兀鹫级` 外带 Genolution 金蛋）与 [空离](../../p/2113198680/)，协同 [抵抗之狐](../../corps/fox/) 的 [兔斯基](../../p/2112441816/)、`休津级` 控场的 [小桔](../../p/2116157769/) 与 [澄明](../../p/2122296275/) 桥到自家星城边。只是谁也不愿先跨出第一步——两支大军就这么隔着网格整整对望了四十五分钟，直到 `PH` 终于下令跃迁进射程。
:::

## 毒蝎压瘫家门口后勤链，PH 打满九十分钟还是退回老房子

一贴进近距，超过三千四百人的 `HB-1NJ` 网格顿时陷入重度时间膨胀。按参战者 `wildfyre010` 在[红迪主帖](https://www.reddit.com/r/Eve/comments/1l3id92/) 里的记录，客户端里按一次武器循环或开关一个装备动辄得苦等三到五分钟，可战果却在这缓慢得像凝固的时间流里一寸寸偏向帝国。

::: 高潮 客厅外摆满金色毒蝎：电子战撕开 PH 后勤，铁壁在眼皮底下顺利立住
平日几乎被加达里蓝壳刷屏的大队战场里，帝国随后亮出了一排醒目的艾玛与加达里电子战阵容——成群 `毒蝎级` 扑上去死死干扰 `PH` 后勤船锁定，后排更架进一队 `灾难级` 远程压制火力。哪怕自己那座宏伟星城就贴在眼前，近在咫尺的建筑距离也替 `PH` 后勤船挡不住半发干扰波。磨完漫长的九十分钟后（全场 `HB-1NJ` 烧掉逾两千五百六十亿、PH 占了超两千亿大头），[PeriodicTpr](../../p/2118325902/) 与指挥组终究面对大联盟最憋屈的那道二选一：继续拼着陪掉整支主力替敌方铁壁续伤，还是趁早带队回星城为下一轮计时留住火种？最后 `PH` 选择撤出，让蜜蜂安安静静完成了铁壁上线；战后 [Ghost与加里](../../p/2120624679/) 放出[《HB-1NJ星系3600人铁壁上线战》](https://www.bilibili.com/video/BV17ET4z6EJi/)，[一捆烂胶带](../../p/2114508645/) 亦连发两期（[BV1qd7ez9EqR](https://www.bilibili.com/video/BV1qd7ez9EqR/)、[BV1gWTpzDES7](https://www.bilibili.com/video/BV1gWTpzDES7/)），把“家门口多出一个拆不掉的新邻居”钉进了记录。
:::

## 次日凌晨星门换成两头夹击，PH 鹏鲲落地就撞进泽尼塔口袋

两场战事在时间上紧贴着缠在一起：早从六月四日十九点出头起，`EFM-C4` 周边就已经零散燃起过一轮逾六百亿的前哨摩擦（像 [PLA](../../corps/pla/) 老将 [一八](../../p/2119472256/) 小号就在交火中交过一条二点六亿战损）；而真正按剧本演出“门口招待”的，却是跨进六月五日凌晨零点五十七分到两点五十六分之间那两小时星门伏击（`16%` 时间膨胀下打掉七百七十一条 KM、逾一千五百三十四亿，将 `EFM-C4` 全夜累积推高至两千一百三十五点七亿）。

::: 高潮 门口布伏、门后下泽尼塔：PH 两百多条鹏鲲落地成盒，Brave 小队清障救旗舰
按当天[红迪 EFM-C4 战报](https://www.reddit.com/r/Eve/comments/1l3nwod/)与快照轨迹回放，帝国事先一步咬死了 `EFM-C4` 通向 `G-QTSD` 的关键星门：这头早已蹲着换乘 `乌鸦级海军型` 打满五十八条记录的 [阿舍](../../p/1687651723/)、[极端荣耀](../../p/1664583033/)（`兀鹫级` 出勤四十条），还有小号刚交过战损的 [小洋](../../p/2114834014/)，外带 [嘎子哥](../../p/2119032128/)、[伊利法尔](../../p/2121295606/)、[曲馨](../../p/2122590961/) 与 [沐雨](../../p/2123483807/) 齐齐架好火力网。当不知情的 `PH` 与友军 `鹏鲲级` 舰队跨门加载进网格时，前门已立满守军，更要命的是星门背后悄然落下大批 `泽尼塔级` 与 `使徒级` 旗舰后勤（包括之前混战中便已损过的八十四点四亿[龙鸟级](https://zkillboard.com/kill/127637444/)）；一时间星门两边前后封死，全夜一共有两百一十九艘 `鹏鲲级` 留在这片入口，连 [抵抗之狐](../../corps/fox/) 的 [兔斯基](../../p/2112441816/)（兼开 `猛鲑` 与 `鹏鲲` 出战）都在一点十六分之后连续赔出三点五亿与三点七亿两条座舰兼蛋才艰难脱身。有意思的是战后评论小插曲——作者原把前来清掉门口拦截与泡泡的 `Brave` `猛鲑级海军型` 小分队顺嘴称为“规模不大”，当场就有参战者出来替这支不起眼的小队讨回体面：正是靠他们死清拦截，投下去的无畏才没有变成没法出门的活靶。
:::

## 四千五百人同夜分站两色：新堡装上了门，回家还要过减速带

跨星系去重核算，这一昼夜合编共卷入四千五百名驾驶员，两千四百余张残骸把近四千七百亿账单划出一道悬殊的比例：守门口又抢门后的帝国一侧两千四百七十九人仅损一千三百九十亿，退回老城又挨夹击的 `PH` 联军两千零一十八人却吞下三千三百零四亿——有趣的是就连 `PH` 这边的名单里，也站着曾与后来对手同场的 [老黑](../../p/2121401697/) 小号等华人面孔，各自按所在舰队的指令在重度时间膨胀里熬完了一宿。

::: 高潮 退回一千五百公里外的大星城，与星门加载画面后的最后一张门票
战后两派在红迪上各自算过一遍得失：支持 `PH` 撤退的人感叹“留得主力在，后续计时还有打头”，笑看戏的帝国玩家则满意于“房子不仅装好了门，门外顺手还收了一顿星门过路费”。从 `HB-1NJ` 那一千五百公里短得让人憋屈的撤军路，到 `EFM-C4` 过门后眼前突然多出的两面夹击，“立起来一座拿不走的堡”和“被关在半路的过门船队”，正好拼齐了那一夜帝国推入因斯姆尔的两块拼图。
:::
