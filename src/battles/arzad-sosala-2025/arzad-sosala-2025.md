同样一个周末，低安星门连着翻了两遍桌面，中间空出来的半日甚至只够各自回家重新装配一艘无畏舰。七月中旬，凌晨的[阿尔扎德](../../battles/arzad-sosala-2025/)建筑争夺战率先滚成逾九千八百七十亿 ISK 的无畏大火拼，让参战作者 `Megaman39` 顺手在红迪挂出一篇[《Waifu War》复盘](https://www.reddit.com/r/Eve/comments/1lz5vwi/)；不等硝烟散透，当晚索萨拉铁壁的结构计时又把几乎同一拨低安熟面孔再次拖上牌桌，硬生生续出四千五百多亿——一天之内合集一千二百一十四名驾驶员、交出七百九十条击毁记录、烧掉约一万四千三百八十六亿 ISK，连 `FL33T` 与 `INIT` 都曾在凌晨和夜幕之间毫不犹豫地调换过座位。

## 凌晨阿尔扎德点响“老婆战争”头炮，同盟表排成临时相逢

::: 高潮 熟人先按盟表排进同一桌：星星、牢陆并肩出阵，红名与玄武双双压进圣卒线
凌晨一时刚过（世界时一点至四点），阿尔扎德首先把规模扯开至五百一十八条残骸、约九千八百七十六亿 ISK。这一场站在 `Snuff` 与 FRT 旗帜下迎战深水、Sedition 联军的低安队伍里，[The Skies Descend](../../corps/the-skies-descend/) 的 [折纸](../../p/94260398/)（驾 `马克瑞级`）与 [少侠](../../p/2118354268/)（驾 `神示级海军型`）携同 [AVDOT](../../corps/avdot/) 班底出阵；[混沌](../../corps/chaos/) 一边有 [星星](../../p/2114362964/) 先开 `兀鹫级` 再换 `永灭级`、老将 [灭绝](../../p/1235367427/) 坐进 `曙光女神级` 控节奏，后勤队列里还能看见 [牢陆](../../p/2123083856/) 开 `战隼级` 一边挨打一边连赔数船加太空舱；[银雾龙骑](../../corps/silverfog/) 的 [红名](../../p/2114820390/) 携 [烈冰玄武](../../p/2120988347/) 同样两头开着 `圣卒级`（后者小号另交护卫与蛋，红名本人连换数船赔了近十亿）站在同一侧。讽刺的是日后团里人事：那时 [牢陆](../../p/2123083856/) 还在混沌跟着 [星星](../../p/2114362964/) 站在同一张舰队表上，没人想得到后来会闹到劝退与限时搬家。
:::

## 凌晨无畏贴脸互砸，008 与小夹子半小时里连交三舰

接战不到一个半小时，阿尔扎德的无畏与战列就进入了毫无缓冲的对轰阶段。对面深水与 `Family Guy.` 阵线里多艘超百亿重舰率先起火（包括几艘约一百四十亿至一百六十六亿级别的高危目标接连落榜），可 FRT 自己的多开无畏队也跟着吃进了成批集火。

::: 高潮 二点三十四分连炸三条八十亿级无畏，008 与小夹子接下重单
进入两点三十四分后的短短六分钟里，[混沌](../../corps/chaos/) 的两位多开好手接连成了焦点。以刷“欧服最大”招新广告著称的 [008](../../p/2121669020/) 先是在两点三十四分五十六秒看到名下一号座下 `神示级海军型` 炸出[八十四点七亿亏损](https://zkillboard.com/kill/128512753/)，不到两分多钟又在两点三十七分十三秒目送另一号驾驶的 `泽尼塔级` 爆出[九十一点二亿](https://zkillboard.com/kill/128512792/)；紧接着两点四十分四十三秒，三开进场的同团骨干 [小夹子](../../p/2119942097/) 也看着小号驾驶的 `神示级海军型` 在三十一人围攻下轰成[八十五点五亿残骸](https://zkillboard.com/kill/128512881/)。整个清晨打下来，Snuff 与 FRT、龙骑及后手合并侧合共交出约四千五百五十三亿亏损，而深水一侧则背上了逾九千七百七十亿的沉重账单。
:::

## 晚间索萨拉同一群人重新洗牌，FL33T 与 INIT 转头站进另一桌

让人看花眼的座位洗牌，发生在十几个小时后的世界时二十点至二十三点。围绕索萨拉一座铁壁的最终结构计时，二百七十二条击毁记录再添四千五百一十亿战损；更绝妙的是，凌晨阿尔扎德战报里原本还站在深水一侧或单列观战的 `INIT` 与 `FL33T`，到了晚间索萨拉竟然齐齐坐到 `Snuff` 这边迎战深水、Sedition 与 `S.U.S`——同一天内换过两次桌的势力，谁也没觉得需要发一纸声明解释。

::: 高潮 陌然换穿深水旗号开起曲剑，狂天带双号入场，支援断档逼退主力
身份与座次的流动性落在个人履历上尤其鲜明：两年前老人星告别战还挂在 `SC` 旗号下的 [陌然](../../p/2114453889/)，此刻早已披上深水旗下 [Family Guy.](../../corps/familyguy/) 的制服，在索萨拉晚场稳稳开出 `曲剑级`（[KM 128533903](https://zkillboard.com/kill/128533903/)）替己方 `巴盖斯级` 舰队压阵护航（小号同场另损一十七点三亿）；另一头伴随 `FL33T` 与 `Snuff` 联手攻城的 `INIT` 阵容里，[狂天](../../p/2116350757/) 开出主小号两艘 `马克瑞级` 压进铁壁边，自家主号亲自留下一条[二十二点三亿亏损](https://zkillboard.com/kill/128533020/)。偏偏这场临时凑桌的大型进攻在紧要关头卡了链条：按 `Megaman39` 的赛后说明，己方旗舰已经落地，外圈常规舰支援却没能按节拍跟上，缺了护航与控场接力，他只得咬牙下令撤出，把索萨拉的后续结构与近万亿级别的总账单交回两家自己慢慢算。
:::

## 口号叫着“老婆战争”，评论区连谁先设局还要再战三百楼

两仗合计烧出约一万四千三百八十六亿，照理说周末也该收摊歇气了，偏偏红迪帖子底下的舆论战刚一开锣比凌晨火拼还要热闹。

::: 高潮 究竟是 FRT 设局钓鱼，还是遭遇打成添兵？评论区争到散场都没认输
`Megaman39` 在[《Waifu War》战报](https://www.reddit.com/r/Eve/comments/1lz5vwi/)里把阿尔扎德升级讲成一次早有安排的剧本——仿佛 FRT 先设局引深水咬钩再顺势收网；可帖子下方立即冒出亲历者反对，坚称最初分明是路边巡逻意外碰擦，双方互叫帮手一步步越添越多。烧掉一万四千多亿之后，各家都不肯放弃把自己说成更有预谋的那一方；至于凌晨同桌的 [牢陆](../../p/2123083856/) 与 [星星](../../p/2114362964/)、晚场换了东家的 [陌然](../../p/2114453889/) 乃至整日两头跑的 [少侠](../../p/2118354268/)，战后各自散进不同语音频道，留下的只有被再一次推高的低安物价表。
:::

::: 评
“老婆战争”的名字听起来像一句顺口起哄的周末玩梗，可凌晨阿尔扎德近万亿、晚间索萨拉四千五百亿的两顿流水席摆下来，没有哪一笔账单肯随口号一起打折。盟友名单一天能重洗两次，设局还是遭遇也能在红迪评论区吵上三天，唯一不会被叙事改写的铁律只有一条：天亮之后，所有人的工业线都得加班重新造船。
:::
