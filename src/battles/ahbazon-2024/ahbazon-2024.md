一座停在低安交通咽喉里的蜜蜂铁壁，把平日各自算盘打得噼啪响的零安与低安势力，全都请进了同一锅粘稠的时间糖浆。近五千名飞行员挤进阿巴宗，上千条无畏舰排着队往网格里填，打到最后连服务器都成了最难缠的对手——在 EVE 里最昂贵的装修，从来不是给房子添砖加瓦，而是两家联军各自砸上几万亿，争这一座建筑今晚到底归谁拆。

## 一座门前铁壁，引来五千人赶集

守方并没有把阿巴宗这座[铁壁](https://zkillboard.com/kill/117504940/)当成可以随手抹去的坐标。帝国掌门 [阿舍](../../p/1687651723/)（那位当年在世界大战里喊麦的“天空元帅”、帝国击杀榜头号常客）与 INIT 盟主 [黑暗闪耀](../../p/1869573834/) 带着帝国、勇敢与龙焰的联军早早把常规舰队与无畏押在铁壁外围；另一头，PH、FRT 拉着北方联军、PL、深水和暗影把近两千八百人的拆迁大队压到了门前，开战前一晚中文视频区就已经挂出了动员风声。连平时专门做新闻切片、当年在欧塔萨塞连自己的船都写进战报的“战地记者” [76](../../p/2117010442/)，这次也跟着老东家 [FV.](../../corps/fuente/) 站进了 PH 与 FRT 的进攻队列，一边开火一边等着回剪辑台交片。

::: 高潮 老东家与新招牌，门外先照面
隔着铁壁最先对上火花的，往往是最熟悉彼此习惯的熟人。在帝国守线的 [PLA](../../corps/pla/) 队伍里，黑影队指挥 [七喜](../../p/703462502/) 主号小号一齐上场——有趣的是，他的小号十年前正是在 FRT 的光月和伏羲发家，如今却把全部精力花在带黑影队找老东家麻烦上，对外打得比谁都勤快，对内甚至连自家老板都能从群里踢出去。而铁壁外面的攻方阵中，曾被早年糊涂账错划过阵营、此战正牌挂在 FRT 旗帜下冲锋的 [创世](../../corps/chuangshi/)、[伏羲](../../corps/fuxi/)、[星尘守护](../../corps/stardust/) 与 [混沌仲裁](../../corps/chaos/) 齐齐压上，与守方这头的 [宽带山](../../corps/kds/) 和 [朱雀](../../corps/zhuque/) 正面撞个满怀。门还没拆，旧交情先在概览里染成了对立色。
:::

## 千艘无畏排队换命，账单先压向蜜蜂

常规战列还没把护盾磨穿，阿巴宗的网格就已经被双方陆续投进来的上千条无畏舰彻底点亮。[Sturmer 战后复盘](https://justabout.com/eve-online/35319/submit-a-battle-report-for-a-may-battle)记下的场面直白而惨烈：战列舰铺完前戏，无畏一条接一条下锚互换，守方蜜蜂光自家就吃下了逾一万四千亿的战损，泽尼塔级、海军型无畏与普通无畏排着队进残骸表。大联盟的船库再厚，到了这种规模的交换里也只是一排排等着工业部门接单的报销邮件。

::: 高潮 龙根主小号四连交，和那些熟面孔的昂贵补损
这场无畏互换把平时藏在后台的账号全都推到了火线上。攻方这边，平时负责全联盟跳桥燃料和快递、动辄在论坛拿一句“不想加”打发申请人的 FRT 大管家 [龙根](../../p/2116225251/)，这晚自己彻底上了头——主号 Greed jf cyno 连同另外三个专用小号轮番进场，单他一人就在阿巴宗交出了一条近一百四十八亿的高价座驾和一条约九十四亿的大船，加上其余战损把一排号都填进了受害榜；一同在进攻线上交出大单的，还有星尘的 [剑穿天下](../../p/2118016008/)（约八十五亿）、[龙裔](../../corps/dragonborn-of-new-eden/) CEO [Akagi](../../p/2113316712/)（小号约一百一十亿）、北方老兵 [李疯子](../../p/2113831237/)（连损约一百亿和十一亿多两张单子）、写教程和搞强暴同样出名的伏羲老人 [叼爷](../../p/1387156123/)（约六十二亿）、在 [联邦空军](../../corps/ef-air-force/) 拍单杀视频的 [飛鳥](../../p/2121130491/)（约六十亿）、军团名专门损着盟主却上场实打实赔了约六十亿的 [大聪明](../../p/2116384303/)，外加四十七秒压完九十个号矿的 [星期三](../../p/2120925108/)（约五十九亿）、隐轰女王 [爱丽丝](../../p/2112491643/)（约五十八亿）、[凤凰城](../../corps/phoenix/) CEO [漫步](../../p/2116726862/)（约五十六亿）、[阙](../../p/2117312483/)（约五十六亿）与 [文华](../../p/2113716167/)（约四十九亿），连 [N老板](../../p/1618197191/) 的小号也在场内留下了一个太空舱。守方这边同样不肯示弱：PLA 总监 [小洋](../../p/2114834014/) 交出约六十二亿，DC 的 [DA](../../p/2114273804/)（约九十四亿）、[木木三](../../p/2114825720/)（约八十六亿）和外交官 [珅](../../p/2118018631/)（约六十四亿）轮流替守军结账，连以单杀和开大鱼闻名的 [赵建国](../../p/2115652382/)（在 [兔飞](../../corps/tufei/) 赔了条金鹏级）和自称“摆烂王”的 ES 掌柜 [星烨](../../p/2120556332/) 这回也老老实实上场交了船。
:::

::: 高潮 黑山羊与双号建团狂人，都在低安熟地抢戏
主力大盟在正面烧得昏天黑地，习惯了低安混战的熟脸也没放过这锅大席。代表深水出战的 [黑山羊](../../p/2115488091/)（个人简介里塞满从 R4 到 R64 矿物表的瑶光 FC）与 [汉堡](../../p/2117195144/)（开着马克瑞级在网格里抢签名）紧咬守方队形；FRT 的赛事老将 [Hoshimati Comet](../../p/2120246500/) 驾着阔刀级重拦在交火区替队伍锁住目标，[慕容](../../p/2114279817/) 一面跟着大队输出，一面不忘搜集前线材料。更有意思的是守方阵中的建团狂人 [绝绝](../../p/2121509601/)——主号挂着 PLA 在高强度对抗里连续交船，无联盟小号 JUEJUEJUE 也跑进同一片星系一起炸掉，平时建团一个接一个换招牌的人，这晚把两本战损账都记在了阿巴宗。
:::

## 糖浆里的慢动作，和停不下来的会战模块

随着本地频道人数冲上四千多，阿巴宗彻底变成了按分钟读秒的慢动作泥潭。无论是多线开火的旗舰、还是想抓时机撤离的常规船，所有人头顶都悬着同一把刀：服务器到底什么时候才轮到处理你刚刚按下的那个按钮。

::: 高潮 掉线四十分钟，只落后锚点四十五公里
严重的时间膨胀在 [Reddit 战后帖](https://www.reddit.com/r/Eve/comments/1cj02o5/)里留下了一串堪称行为艺术的奇观。一位名叫 Phoenix4264 的常规驾驶员中途掉线了整整四十分钟，好不容易重新连回阿巴宗的网格，定睛一看，发现自己的船居然只落后舰队锚点四十五公里——在平时几秒钟就能追上的距离，这晚靠着时间膨胀硬是熬完了大半顿晚饭的时间。另一头，lobuzjeden 的遭遇更让无畏驾驶员血压拉满：他在停战模块还剩四十五秒时就老早发出了停止指令，服务器却硬生生拖了超过两分半钟才把命令放过去，结果绿灯没等熄灭，己方三条泽尼塔级已经排着队成了残骸。在阿巴宗的糖浆里，人已经想撤了，船还在替两分钟前的那道命令尽忠。
:::

熬到凌晨四时三十八分，这座让几家大联盟轮流押上家当的蜜蜂[铁壁](https://zkillboard.com/kill/117504940/)（估值约二百八十四亿 ISK）终究在集火中轰然解体。蜜蜂、INIT 与帝国联军一共付出了约两万六千一百八十六亿（一千一百七十一条损失记录），PH、FRT 与泛星系联军也交出了约一万八千零四十九亿（九百八十三条损失记录），全场合计烧掉约四万四千二百三十五亿。守堡的一方做完了能做的一切，最终还是只能看着坐标从星图上被抹掉。

## 撤退先交高安罚单，大内宣连夜打补丁

铁壁炸成烟花之后，阿巴宗的节目却还没有落幕。疲惫不堪的舰队顺着星门往外撤，留在战报里和 B 站视频区的第二轮嘴仗才刚热身。

::: 高潮 没死在五千人手里，回家路上先吃高安警察罚单
最具黑色幽默的收尾属于 INIT 的一支狂热级舰队。从几千号人和上千无畏的绞肉机里好不容易熬到散场，这支队伍转道从低安跳进了高安准备回家，结果刚一露头就被当地执法力量当场拦截收船。战后 [Reddit 楼里](https://www.reddit.com/r/Eve/comments/1cj02o5/)立刻吵成一团：有人坚称是队员误射了红名 PL 流浪级才触发了严厉制裁，另一派则反驳多数损失分明挂着嫌疑标记和加达里警察的印记。不管究竟撞上了哪条交规，结局早就替飞行员写好了嘲讽：五千人的大军没能把他们全留下来，回家的警察顺手帮敌对补上了这一课。
:::

::: 高潮 一碗水没端平，大内宣连夜给深水补道歉信
场外的 B 站视频区同样热闹得像第二片战场。打完仗次日，亲自下场赔了船的 [文华](../../p/2113716167/) 剪出[《阿巴宗无畏决战！凛冬华人联盟群劳动节旗舰攻势纪实！》](https://www.bilibili.com/video/BV13C411n7wm/)，第一版为了省事把视角全给了零安三大势力，将深水等低安客卿一笔带过，结果立刻引来深水方面的不满与质疑。文华只好连夜发了一篇长长的更新补丁，在简介里一面立正承认“深水出了大力拿了大鼎”、把他们补写为 PF 邀请赴宴的客人，一面干脆撕掉客套直接宣告“我只是一个只属于 FRT 的大内宣，不做赛博客观第三方”；紧接着还不忘在比喻里顺手扎深水一刀——阿巴宗大饭店是 PF 联盟群做东请客，席间摔筷子夹菜都正常，只是想到深水华人团刚和 DC 谋划着埋超旗马甲，“让熊猫说深水是友军未免太强人所难”。同一时间，[慕容](../../p/2114279817/) 也以“凛冬社记者 Garveen”的身份替[《阿巴宗无畏大战，蜜蜂违章拆除》](https://www.bilibili.com/video/BV1EC411E7qb/)供稿，[Freak 03](../../p/2113467365/) 端出[七分钟速览](https://www.bilibili.com/video/BV1jf421U74Q/)，海外 [Xeron Vann](https://www.youtube.com/watch?v=3Pc7XH-NiEw) 则顶着时区差把日期写成了五月四日。建筑是拆完了，评论区里的饭桌倒是又摆开了一轮。
:::

::: 评
阿巴宗这一夜，拆家和守家都很认真，认真到那座价值不到三百亿的铁壁，最后成了全场最便宜、也最不需要解释的损失。它至少能说清自己为什么炸：对面本来就是来拆它的。

旁边那一千多条无畏、四万四千亿的账单、卡在糖浆里停不下来的模块、高安门口的警察，还有连夜打补丁的“大内宣”，则要各自回去回答同一个问题：为了拆掉或者留住这么一栋房子，船厂的加班费到底准备开到几月？
:::
