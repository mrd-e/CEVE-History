低安星系阿巴宗的星门向来是一张明码标价的赌桌，八月头一晚更干脆把擂台搭给了全宇宙所有路过凑热闹的人。Minmatar Fleet Alliance 带着友军把成队无畏开进主页桌面，INIT、SND、Dragon Riders Legion 与 TEST 摆出另一张旗阵正面对轰，而站在旁边冷眼看戏的 FRT、Solyaris Chtonium、SYN 以及来自 00 区的众多客人干脆全按第三方挂牌进场。四个半小时、近两千名飞行员混作一团，六千四百多亿的残骸在星系里漫天打转——有人按大船押注，有人只拿小船进场捡漏，最后照样各自在账本上签了名。

## 三路算盘压境，萨拉希尔与猛烈先烧天价

诱导才刚在低安星门上亮起来，阿巴宗这口大锅就已经被三边不同的小算盘烧开了：`Minmatar Fleet Alliance` 拉起 `Minmatar Fleet Associates` 和 `Amarr Fleet Alliance` 五百多人把主力压到星门正面，摆明了要跟对面一决高下；迎战一侧的 `INIT`、`SND`、`Dragon Riders Legion` 与 `TEST` 也不甘示弱，龙骑当地驻扎的 [银雾龙骑](../../corps/silverfog/) 与 [沉默旅人](../../corps/sojourner/) 亲自披挂坐镇本土星门；偏偏最让两边指挥头大的，是围在战圈外边足足六百二十八名第三方闲人——从 `FRT` 到 `Goonswarm`，外加 [PLA](../../corps/pla/)、[AVDOT](../../corps/avdot/) 等一群看热闹不嫌事大的中文游骑，个个手里攥着重船瞄准残血，谁先亮红灯就上去咬谁一口。

两边重器还没全部铺开，外圈的旗舰猎手先把阿巴宗烧出了第一波高价天灯。十七时三十九分，场中一艘造价高达 **六百六十四点四亿的萨拉希尔** 遭到两百八十一名参战者集火撕裂（伤害榜首落在一条台风级名下）；到了十八时过后的混战峰值里，一连串平时在低安难得一见的重型实验船与高价配件排着队变成废铁。

::: 高潮 萨拉希尔与双猛烈级炸穿桌面，T2 指挥航跟着连环坠地
十八时零一分起，阿巴宗的击杀播报连续飙出惊人价码：先是一艘约 **一百六十一点三亿的盖亚级** 在四百七十八人集火下炸碎；仅仅三分钟后的十八时零四分，一颗估值 **一百八十七点一亿的特制金蛋** 在炮火里化作烟雾；紧接着十八时零七分与十一分，两艘超过 **五百亿的猛烈级** 前后脚倒在战场当中（其中一条记在 `Minmatar Fleet Alliance` 名下，约五百零三点六亿），中间还夹着一艘 **一百四十八点八亿的血鸦**；到了十八时三十九分，一艘约 **一百三十五点二亿的特种指挥航母** 也在百余条火炮下收工。难怪赶来混战的 [一捆烂胶带](../../p/2114508645/) 回头剪录像时，标题开口就先点出“T2指挥航连续陨落 高低安零零各势力自由开火”。
:::

## 狂暴换神示，龙骑团把账单翻到旗舰一页

高价势力的天灯把场子烧热之后，真正决定账单厚度的还是两主战阵营一排排进场的常规无畏与战力辅助舰。`SND` 在战报里一口气亮出十九名无畏驾驶员，`Dragon Riders Legion` 与 `TEST` 也各把无畏压上火线，迎着对面的神示级与尼铎格尔级一轮轮互砸。

只是在阿巴宗这种多方乱斗的场地里，只拿大船硬抗远远不够，站战列线的华人老海盗同样在风口浪尖里轮流翻身。`INIT` 这一回虽然出动两百三十四人站到无畏诸部一侧，整场却把绝大多数损耗压到了外线，仅仅留下一笔约两百五十二亿的轻量支出（两条凤凰级海军型就占去一百四十六点五亿）；倒是低安本地的[银雾龙骑](../../corps/silverfog/)与[沉默旅人](../../corps/sojourner/)顶在热线上，把小船和无畏的代价全尝了个遍。

::: 高潮 从暴风换到无畏，雨季替阿巴宗交了两档学费
站在 `Dragon Riders Legion` 一侧的[银雾龙骑](../../corps/silverfog/)这天几乎倾巢而出：当家[红名](../../p/2114820390/)开着狂暴级领队打了二十五次击杀，平日只留下一条频道书签名四处漂泊的[沉默旅人](../../corps/sojourner/)新老板[奈何](../../p/2118160416/)也在同一排狂暴级阵线里打出十八次击杀。偏偏同团的[Awakeallnight](../../p/2114626303/)（雨季）这回偏要逆着高延迟硬加码——这个角色安全等级负九点四、平时最擅长把低安大战剪成数万播放量中字录像的“自由海盗 红龙”，十七点五十九分先在第一波对射里丢了一条约二亿六千万的狂暴级，结果他回站二话不说换上一条 **神示级无畏** 重回火海！十八点二十三分，他的神示级一炮拿下对手一艘埃拉兹级的伤害榜首，紧接着没撑过十二分钟，到了十八点三十五分三十二秒，这条估值约 **四十八点七亿的神示级** 也轰然炸毁。别人战后翻联盟总账数战果，雨季翻自己的仓库先看见同一晚从战列舰翻到无畏的两档学费，只好转身回 B 站发出一期《6000亿战损！阿巴宗千人会战》替大家算一笔清账。
:::

## 第三方百团混水，狂暴与十字军钻进旗舰缝里

主战两家的神示与泽尼塔在场地中心互相点名时，从四面八方跳进来的第三方早就不客气地开了锅。包括 [PLA](../../corps/pla/)、`FRT`、`AVDOT`、`SYN` 和游骑团队在内的六百多名第三方成员各自挑好顺眼的猎物开火——主战场大船把彼此血量啃空，外圈战列和高速护卫专负责钻进旗舰缝隙里切脆皮、拦后勤。

::: 高潮 大船的买卖，三百八十杀的十字军与战列也来赶集
第三方阵营里，刚转进 [PLA](../../corps/pla/) 半年的前星华旧部、平时录了七百多条教程视频兼做军团招新喇叭的[一捆烂胶带](../../p/2114508645/)，和老板[极端荣耀](../../p/1664583033/)、教程名师[青春](../../p/2114969276/)一齐踩着狂暴级压进战圈，连上个月刚带着三个小号同一分钟跳进 [AVDOT](../../corps/avdot/)、平日在贴吧封号“帝国眞理部”的[方小明](../../p/2113415433/)也开了台风级挤进炮线。结果打到头来最红眼的竟是平时教人刷血袭者异常的[青春](../../p/2114969276/)：主号全程狂斩 **三百八十次击杀**，期间先后在十八点零八分丢了二亿七千万狂暴级、十八点三十六分再交一亿四千万毒蝎级，末了还不忘抢下一条守卫级后勤的最高伤害，另外小号 `KISSMYASSTHX` 也在十八点十二分搭进去一条三亿三千万的拉克希斯级；旁边[极端荣耀](../../p/1664583033/)也在十八点零一分交出约二亿七千八百万的狂暴级后转乘万王宝座级打满二十二次击杀。相比这批忙着重炮抢分的大战列，FRT 反时区常备指挥[W佬](../../p/93331025/)与[混沌](../../corps/chaos/)摸鱼手[哈威](../../p/2123311408/)偏偏挑了小巧的十字军级钻进旗舰肚皮底下讨生活——哈威带着二十七杀全身而退，平时习惯替别人讲课的 W 佬反而在十九点三十九分被送掉一条两千九百万的十字军级，算在人潮最拥挤的教室里交了回低价学费。
:::

## 四小时混战收票，千人各自结清账单

世界时二十一点二十五分，这场从傍晚缠斗到深夜的阿巴宗混战才算慢慢收声。一整张汇总清单摆在眼前，一共清点出一千三百七十三条损失记录、接近六千四百二十六点三亿总损耗：正面对撞的 `Minmatar` 及无畏友军五百四十六人扛了最沉的三千六百七十八点四亿（光 Minmatar Fleet Alliance 本盟一百一十人就背了一千六百四十四点九亿）；`INIT`、`SND`、`Dragon Riders Legion` 与 `TEST` 等七百八十五人付出了约两千零八十九点八亿（`Dragon Riders Legion` 与 `TEST` 各掉六条无畏）；而高喊自由开火的第三方六百二十八人合计仅付六百五十八亿。

::: 高潮 门票买得便宜还是贵，全看你敢不敢把大船押上来
散场回头复盘，最有戏剧性的对比并不在嘴仗上，而在每张账单的人均厚度：`Minmatar Fleet Alliance` 百来号人押进旗舰与猛烈级，人均分摊直接飙到十余亿；而蹲在另一边的 `INIT` 虽然照样拿了两个多百人撑起排面，全盟总损却只落在两百五十二亿左右；赶集来的 PLA、FRT 等第三方尽管也有青春连炸三船、胶带扛着卡顿开火的热闹场面，均摊下来仍是全场门票最便宜的一批。正如[一捆烂胶带](../../p/2114508645/)自己发片时说得直白——“整场战斗虽然时间膨胀严重，但是总体来说是爽射”。
:::

::: 评
阿巴宗这天的生意确实兴隆：有人拿几十亿上百亿的天价实验船当入场券，有人先交暴风再加码神示连买两张门票，也有三百八十杀的猛人把战列和电子侦察船当成日用品往下填。

近两千个角色挤进低安门前这间大教室，各自怀揣着截然不同的算盘和频道列表；战报合上的那一刻，谁都没有空手离开——只是有人揣走了一串好看的击杀数字和几段 B 站高燃剪辑，有人回家翻仓库，先看到自己那排补不完的无畏缺口。
:::
