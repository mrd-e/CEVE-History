谁也没料到，新伊甸史上最贵的一场泰坦大葬礼，导火索竟然只是管理界面里一个忘了打勾的自动续费选项。万圣节战争打到深冬，N3／PL 把大批作战家当停在 `B-R5RB` 的空间站里当作前线集结地，偏偏主权刚交到 H A V O C 手上，自动缴费却没接上，整座星系的控制权在周一午后当场掉落。

这下连战前动员都省了：俄罗斯联军与 CFC 闻风扑上来抢占星系，一旦空间站易手，停在里面的船就会变成进得去、拿不出的死资产；N3／PL 只能硬着头皮把全家老小拖进星系救场。原本一笔小钱就能勾掉的账单，硬生生拖成七千五百多号人连打二十一个小时、砸沉七十五条泰坦、烧掉约十一万亿 ISK 的大清算——只不过越打到后半夜，账单越像单方面催收：N3／PL 交出五十九条泰坦，CFC 与俄罗斯联军只交了十六条。

## 欠费一张单，两边先抢门槛与路口

主权刚刚掉落的消息传开，两边指挥几乎在同一时间看懂了这座星系的份量。N3／PL 的第一反应是趁敌方大部队还没赶到，火速派人试图重新上线主权设施，却被提前扑进星系的先锋直接击毁；退路一断，N3／PL 只能把航母与超航往空间站外一摆，重新架起几天前刚在 `HED-GP` 奏过效的“毁灭球”维修阵，指望靠着重重后勤硬扛到增援进场。

然而这一回站在对面的 CFC 与俄罗斯联军，手里拿着刚从上一场败仗里抄来的笔记。

::: 高潮 上次在 HED-GP 挨了打，这回先把路口堵死
几天前的 `HED-GP`，CFC 与俄方刚吃过 N3／PL“毁灭球”抱团维修的亏；到了 `B-R5RB`，对面还想照搬同一套剧本守住空间站门面。CFC 与俄方这一次直接抓住周一工作日突发交战、守方主力尚未集齐的空当，果断把整支旗舰力量压上前线抢占数量优势，不给对面慢慢攒齐维修圈的机会。

与此同时，常规舰队也被大批派往 N3 周边几个必经的集结点——卡罗尔、`I-NGI8`、`GXK-7F`、`KDF-GY` 的星门与跳点很快成了伏击圈，想来救场的人得先在半路上过一道关。泰坦在主战场比谁更扛得住，外围小船则在替它们决定对面下一轮还能多来多少条；大船的胜负，先从路口收起了过路费。
:::

## 小船无畏挤上头等舱，华人老人分坐红蓝两端

随着最高同屏人数顶上两千六百七十、全战七千五百多角色陆续拥进这片星域，泰坦、超航、无畏与常规护航线彻底搅成了一锅。在这场后来被写进全服编年史的超级会战里，日后在华人圈和外服各自呼风唤雨的大人物与老熟人，彼时大多还只坐在各自联盟名册里一个并不起眼的格子上，分坐在红蓝两张桌子对面。

::: 高潮 未来皇帝开黑鸦，欧服老师傅拿无畏签十七条
CFC 一侧的队列里，日后接替[米塔尼](../../p/443630591/)执掌帝国的[阿舍](../../p/1687651723/)那时刚进 GoonWaffe 不到一年，距离坐上“阿舍皇帝”的位子足足还有八年——这一天他规规矩矩开着一条黑鸦拦截舰跟着大队上场（[36257158](https://zkillboard.com/kill/36257158/)），替自己攒下了早年账本上最肥的一页。史书写的是泰坦和上万亿的账，当时谁也不会留意一条小护卫舰的主人日后会加冕。

同在蜜蜂阵营 SUNDERING 里的[叼爷](../../p/1387156123/)则坐进了更大的驾驶舱，开出一条纳迦法无畏舰直接扎进泰坦火海（[36255172](https://zkillboard.com/kill/36255172/)），一天之内把名字签上了十七条泰坦的大单。后来华人圈对他的印象常常纠缠在跳货教材、高安强暴和贴吧录音纠纷之间，可翻回 B-R 的账本，这位老师傅确确实实把无畏开进过游戏史上最贵的名场面。
:::

::: 高潮 FRT 站在另一边，签名王者撞上“贵族老板”
对面的 N3／PL 阵线里，2013 年才刚从盘古分家独立出来的 FRT 也带着老团[行星之光](../../corps/lotm/)挤进了名单：[令狐聪](../../p/624049117/)照旧挑了一艘便宜跑得快的黑鸦拦截舰钻进泰坦群里拼命签名（[36254537](https://zkillboard.com/kill/36254537/)），当月参与击杀总额一下冲上七点六万亿，从此把“签名王者”四个字稳稳挂进了自己的角色简介；同团创始人[内森](../../p/133854609/)——那位头衔一口气挂着带商标的“CEO™、贵族、战斗英雄”的老老板——也亲自开着一条执政官航母进场占座（[36241010](https://zkillboard.com/kill/36241010/)），拿下了自己生涯最高的单月万亿击杀记录。

连早年在闪电和盘古做斥候、后来专靠在 BWF 星门经营“断头台收费站”闻名的[水哥](../../p/91282906/)（[36238508](https://zkillboard.com/kill/36238508/)），以及当时还在 Nulli Secunda 替 N3／PL 卖力扛住蜜蜂炮口、八年后却自己跳进 Goonswarm 走正门当起“Progoonlegend”的 [PGL](../../p/317012339/)（[36248517](https://zkillboard.com/kill/36248517/)），全都站在这一边把船开进了火场。泰坦烧出的光足够照亮整个新伊甸，站在光里的熟人们，当年也并非都坐在赢家那一侧。
:::

## 死磕一条指挥泰坦，账单开始往一边倒

最初几个小时里，双方泰坦你来我往一换一，战线尚算胶着。可随着交火拖进中盘，N3／PL 一边在人数和增援通道上渐渐吃紧，另一边指挥席的一次换手和一次执拗的点名，彻底把整场的交换比拧向了一边。

::: 高潮 盯着 Sort Dragon 一条杀，自己先赔掉五条泰坦
据 [CCP 的战后总结](https://www.eveonline.com/news/view/the-bloodbath-of-b-r5rb)，战斗打到中段，N3／PL 的现场指挥权从 Manfred Sideous 交接到了 Vince Draken 手中，随后全军立刻调转炮口，把火力死死压向负责协调俄方舰队的 [Sort Dragon](../../p/1272172192/) 所驾泰坦（[36239111](https://zkillboard.com/kill/36239111/)）。擒贼先擒王当然有道理，坏就坏在 Sort Dragon 那条高抗性泰坦加上俄方整队不计成本的遥修，硬是把全场的集火死死拖在了原地。

N3／PL 盼着对面指挥再抖两下就炸，把宝贵的时间和一轮轮末日全填进了同一个目标；可等他们终于砸穿 Sort Dragon 泰坦的外层防御、逼近结构临界时，CFC 与俄方已经趁着这口喘息接连敲掉了 N3／PL 五条泰坦。点名越响，越像替对面指明了一面绝对不能倒的旗帜；自家的账本先越滚越厚，再想扳回来已经来不及了。
:::

## 十二小时后才喊撤，泡泡里的退场门比进场窄

当泰坦损失的缺口越撕越大，N3／PL 终于意识到靠“毁灭球”和死磕指挥官再也换不回这座星系的主权。然而真到了喊撤的时刻，大家才发现打进来容易，想把剩下的大家伙活着带出门却难得多。

::: 高潮 十二小时后撤退令下达，进场的桥变成了出不去的笼
打到约十二个小时，N3／PL 终于下令全军撤退，可铺满整个网格的拦截泡泡并不会跟着指挥官的一句口令自动消失。来时是气势汹汹的增援，走时便成了被按在泡泡里排队点名的活靶子；更多泰坦、超航和普通旗舰在艰难的撤离拉扯中接连爆炸，炮声一路拖到次日服务器例行维护才被迫收兵。

真正让这场五十九比十六的惨败难以下咽的，是它偏偏发生在自家的前线集结地：本来砸锅卖铁是为了保住空间站里锁死的资产，最后连已经开到站外、原本能随时跳走的超旗也得抢着救。[CCP 的战后报道](https://www.eveonline.com/news/view/the-bloodbath-of-b-r5rb)把主星系与外围截援的十一万亿账单完整挂了出来，B 站上也留下了《尘封的历史-回顾B-R5绞肉机》等玩家整理的录像与讲座，甚至宇宙里还替那七十五具泰坦残骸立起了一座叫作“泰坦墓园”的永久纪念碑——战场上的每一次“再来一轮”，最后都成了机库里缺掉的一排位置。
:::

::: 评
B-R 给新伊甸上了一堂最昂贵的财务课：自动缴费的勾选框很小，能装进去的泰坦却很多。后来的人谈指挥、谈后勤、谈联盟兴亡，最好也留点敬意给那个不起眼的复选框——它没有一门炮，却挑起了十一万亿的账。
:::
