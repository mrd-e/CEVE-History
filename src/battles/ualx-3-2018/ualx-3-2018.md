特里菲斯星域 `UALX-3` 这座刚下水的星城，原本是 Legacy 打算挂在南方前线的门面招牌，结果开业剪彩还没吹上蜡烛，北方联军与凛冬联手上门把它的锚定计时直接敲成了旗舰展销会——只是这场展会卖出去的船，不发提货单，只发击杀邮件。

还在最后锚定倒计时里的星城，让两边谁都退不起一步：对 TEST 和 Legacy 来说，保住它就能把帝国的支援支点楔进南境腹地；对 FRT、PL、NC. 与南方联军来说，趁建筑还没上线加好燃料、把账单一次性买断在今天，远比往后一层层磨盾磨甲划算。按 [当日战况](https://evenews24.com/2018/07/19/breaking-battle-rages-for-test-alliance-keepstar-ualx-3/)，交火从常规前锋一路升级到泰坦与超旗贴脸对砸，整场已核高值损失样本就超过一万三千六百亿 ISK；建筑可以拆掉，已经跳进来的超旗，却没法像关店招牌一样说收就收。

## 开业剪彩变成两群人的拆迁竞速

七月的南境早已被各方喊成了“全服混战”（B 站视频[《EVE - 星城两连爆！这已不是游戏，而是真正的战争！》](https://www.bilibili.com/video/BV1hs411K7ND/) 干脆称之为“Everyone vs Everyone”）。守方的 Legacy 由 TEST 领头并拉来了远道而来的 Goonswarm 等帝国援军，两千五百多个公开角色在星城周围铺开防线；攻方的凛冬与北方联军则由 PL、PH、FRT、Triumvirate.、NC. 等联盟凑出两千一百多号人马，连着重兵直扑 `UALX-3`。

两边还在星城网格里试探阵位时，站在同一片太空里的华人面孔就已经把几年后的阵营剧本先演了一遍岔路。

::: 高潮 站错边还是站早了？建军与阔阔的日历反差
后来读者最熟悉的[建军](../../p/96280212/)，是在 FRT 的怯薛军团里跟凛冬众人并排写进战报——无论是后来在 A1-AUH 开阔刀重拦钉人，还是在 1N-FJ8 坐进救世级，都是妥妥的北方自己人。可把日历翻回 `UALX-3` 这一天，他却挂在蜜蜂旗下的 Never Let You Down，开着万王宝座战列舰站在帝国与 Legacy 一侧，隔着星城朝后来的同盟旗舰开火（[71333249](https://zkillboard.com/kill/71333249/)）。

偏偏同一时刻站在北方阵线里的，还有[星华](../../corps/sing-hua/)出身的[阔阔](../../p/2113160766/)（[71331234](https://zkillboard.com/kill/71331234/)）——这位日后以“六开无畏跳进战场”和贴吧删帖风波出名的老板，此时还跟着北方联军一起敲 TEST 的星城，却在几个月后便转进 TEST 旗下的永夜之剑，从此变成天天上门反打凛冬的对手。人还是那几个人，频道与蓝加却未必还是原来那套。
:::

## 无畏海硬换泰坦墙，招牌还是炸在了门口

进入主战阶段，双方再也没有留半点情面。据 [当日战况](https://evenews24.com/2018/07/19/breaking-battle-rages-for-test-alliance-keepstar-ualx-3/) 与 [TAGN 次日回顾](https://tagn.wordpress.com/2018/07/20/a-keepstar-dies-in-tenerifis/)，Legacy 一边拼命把一轮轮无畏投进北方联军的泰坦墙里，试图以低一档船价换掉对面最贵的旗舰核心；凛冬与北方联军一边则让超级旗舰和战力辅助舰稳住阵脚，把全部火力死死压在即将结束锚定的星城主体上。

::: 高潮 三百多条无畏往里填，门面没保住，泰坦照样沉
星城还在锚定，正是最适合拆的那一刻：一旦让它正式上线加满燃料，往后就得一层层磨盾、磨甲、磨船体。Legacy 于是反复投下无畏去轰对面的泰坦和支援旗舰，用一批批近身开炮的船硬换更大的目标。到 [当日直播帖](https://www.reddit.com/r/Eve/comments/9025w2/ualx3_keepstar_anchoring/) 的上午九点半阶段账单里，Legacy 与帝国已经交出三百三十九条无畏和四条泰坦、连同星城合计约一万四千五百亿，东方与北方联军也已经拆沉了九条泰坦、烧掉约一万零九百亿，随后帖主又补记了第十条攻方泰坦倒下的消息。

星城最终没活过开业礼，在炮火里炸成了残骸。可建筑爆炸并没有让旗舰战自动散场：当日更新点名 FRT 的神使泰坦在交火中被毁，直到八点多仍有无畏增援往里跳——拆掉星城和保住大船在这里是两份得分别交卷的差事，前一份拆完了，后一份还在炮口底下接着考。
:::

::: 高潮 老板亲坐使徒吃炮，名将坐镇指挥位压阵
这一夜坐进北方旗舰海里的，不只是外服联盟的牌面人物。平时军团招新挂着“小而精、兄弟情分”招牌的[雷爪舰队](../../corps/tcf/) CEO [D哥哥](../../p/690534767/)，真到了泰坦对泰坦的硬局里直接开出一条神使泰坦亲自下场（[71333249](https://zkillboard.com/kill/71333249/)），正好跟对面建军的万王宝座挤进了同一份记录；日后常在动员公告与《N子兵法》里讲大局的[N老板](../../p/1618197191/)，这晚也用小号 Randolph Yuan 开着一条使徒战力辅助舰进场替舰队补血，结果在七点刚过被砸成约二十四亿的[旗舰残骸](https://zkillboard.com/kill/71332828/)——坐在管理席上时能把损失称作“战略投入”，轮到自己的使徒炸在网格里，那个词就会具体不少。

而在负责协调欧美侧阵脚的关键席位上，曾经把黑军团抢回来却又手滑在界面里把自家联盟点解散的名将 [Elo Knight](../../p/1511725012/)，这一场稳稳**坐镇指挥位**压阵到底（[71330132](https://zkillboard.com/kill/71330132/)），替北方这群拼盘盟友兜住了白班与夜班交接的火线。
:::

## 节点一卡，赢了拆迁的人被关进了超旗监狱

星城刚被拆平没多久，真正的转折却不是哪一方打穿了防线，而是服务器自己先撑不住了。世界时九点前后节点崩溃，赢下拆迁目标的北方与凛冬超旗编队没能一齐跳出 `UALX-3`，等服务器缓过神来，整片星系已经变成了另一番光景。

::: 高潮 拆完旧店没法走，房东在废墟上又支起新招牌
节点崩溃把大批攻方超旗卡在了掉线坐标上。据 [TAGN 次日回顾](https://tagn.wordpress.com/2018/07/20/a-keepstar-dies-in-tenerifis/)，Legacy 反应极快，立刻将大量拦截泡泡铺满对手掉线的位置与各处星门，守着人重新上线，生生把一场失去建筑的防守战接成了一场不让客人离席的围困；转眼之间，新的星城与铁壁又往附近拍了下来——旧店虽然拆了，房东却在原地支起新招牌继续营业，攻方的胜利宣言还没凉，登录按钮先成了一道要商量着按的选择题。

这场围困随后几天甚至直接惊动了客服。7 月 21 日，[CCP 公开说明](https://www.eveonline.com/news/view/ualx-3-fleet-fights-misfiling-of-stuck-tickets)：有联盟领导号召成员提交“卡住”工单要求把旗舰挪出 `UALX-3`，官方明确拒绝替大规模交战中的旗舰搬家，并警告组织刷工单可能构成滥用。带跳跃引擎的船得自己找办法走，泰坦也没有客服专用逃生门。
:::

::: 高潮 对面拉起战备警报，N老板在会议室里唱起了歌
超旗被困在“监狱”里整整僵持了好几天，外面守门的舰队生怕里面随时找机会突围，里面的驾驶员也绷着一根神经。可据[知乎亲历回忆](https://www.zhihu.com/question/285967560)，僵持期间有一天 [N老板](../../p/1618197191/)突然把一大帮人叫进了语音频道会议室。

对面的 TEST 眼线一听里面大人物全进会议室了，立刻以为北方要强行组织越狱，火速把大批人马拉起来进入战备待命；结果等了半天，会议室麦里传出来的并不是突围指令，而是 N老板在里面唱起了歌。关在超旗监狱里的老板把动员开成了联欢，外面按大战备勤的敌军只好跟着白听了一轮前奏。
:::

## 关服前五秒压线越狱，视频搬进B站继续算账

围困最终还是在多方掩护与维护窗口的缝隙里找到了出口，B 站随后不仅出现了专门复盘这段幕后脱险的视频，国内亲历者自己也留下了比战报还惊险的回忆录。

::: 高潮 借来的泰坦一直掉线，娃娃在关服前五秒才想起怎么跳
平日里开视频教学高喊“三开大航不是梦”的[娃娃](../../p/96548383/)，在贴吧《欧服周年回忆录》里写下了最像“娃上将”本人的一幕：这场他向朋友借了一条神使泰坦进 `UALX-3`，结果只在星城上签了个名，剩下时间几乎全程掉线，急得号主在频道里一直喷他。等到终于决定撤离，N老板让所有泰坦吃电池、换扫射炮清拦截、最后喊能跳的赶紧跳走——娃娃却脑子一抽，率先点击跃迁向了本地一座小堡垒。

飞到半路他才猛然反应过来：老子开的是能旗舰跳跃的泰坦，跃迁去小堡垒干什么！此时临近例行维护，落点还有敌对拦截与泡泡蹲守；按他自己的说法，偏偏就在关服前最后五秒，泡泡刚好消散，他疯狂右键电容、狂点跳跃，总算赶在关服窗口弹出来之前压线落到了诱导铁壁。同一批守在北方的阵营里，当时还在 PL 出勤的[拉面林](../../p/91309503/)（[71329852](https://zkillboard.com/kill/71329852/)）后来也亲自搬运了[《价值百万美元超旗逃脱幕后》](https://www.bilibili.com/video/BV1Gs411A7Xe/)，把这群泰坦怎样策划越狱的幕后摊在了 B 站观众面前。
:::
