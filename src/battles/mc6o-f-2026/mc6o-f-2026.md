春初的 `MC6O-F` 刚打响没几分钟，一边刚从被窝爬起开火的泰坦就已经把射程直接架到了对面无畏脸上。三月一日中午，FRT 带着北方盟友在单星系 `MC6O-F` 凑出一百零二条泰坦与五十余条超航的恐怖阵容，正面迎战主要由 INIT 与 Snuffed Out 领衔、加上 Goonswarm 等联军的纯常规与无畏大队——整场只打了一小时出头，九百八十四名角色、七百一十八张击毁记录便合出 **一万一千四百一十七亿 ISK** 的史诗级账单。在超过百条泰坦的末日武器面前，对阵那支靠神示级无畏顶在最前排的联军几乎按排被点名融化；只是谁也没想到，在这张满是神示残骸的万亿大账里，最先破产的竟然还有几个在门口探头的黑隐熟人，以及一艘开着工业旗舰混进群殴里狂舔近三百杀的二十年老将。

## 刚睡醒先点黑隐，泰坦开桥迎面砸进百条无畏群

世界时十一点二十三分起，`MC6O-F` 的局势几乎在一分钟之内便失去了所有客套。北方阵营由 FRT 连同友军一共推进了六百多人（仅 [SARD 特别执法部](../../corps/sard/)、[混沌](../../corps/chaos/) 与 [Arknights](../../corps/arknights/) 三家主力便已近两百号），而且手里藏着随时可以拍下来的百条泰坦底牌；迎面硬顶的 INIT、帝国与 Snuffed Out 三百七十余人虽然人数只及对面六成、身边也带着 Snuff 旗下的 [AVDOT](../../corps/avdot/)、[天降](../../corps/the-skies-descend/) 以及 Goons 这边的 [PLA](../../corps/pla/) 和 [昆仑](../../corps/kunlun/)，却压根没料到对面早把整张超旗跳板支在了自家脸上。

开打头五分钟，重兵未全面接火前，两边的前锋黑隐与重拦先在门口碰掉了满地残骸：神农主力 FC [出其东门](../../p/2120025597/) 驾着救世级率先在十一点二十三分连下对面两条救世级的伤害榜首（收尾还交掉一个五亿多的移动牵引装置）；正坐镇本场核心指挥链的“睡觉大王” [汉兰达](../../p/2115597604/) 先在十一点二十三分用救世级抢下一条十二亿黑隐战列的榜首，隔了一分钟自己的救世级（十三亿）与太空舱也先后遭到反扑炸碎，好在他随即稳坐指挥席把主力调度稳稳攥在手里。可对面 INIT 与帝国一侧的黑隐小组丢得更肉痛——从十一点二十六分起，熟脸的名字接二连三被钉上了击毁榜。

::: 高潮 熟人分坐两边对射，天降黑隐、PLA 寡妇与昆仑救世齐上账
十一点二十六分零七秒，PLA 黑影队指挥 [七喜](../../p/703462502/) 的主号率先交出一条十二亿的救世级黑隐战列舰和蛋壳；仅仅三十六秒后的十一点二十六分四十三秒，同在 PLA 阵中的 [小洋](../../p/2114834014/) 跟着赔掉一条十七亿的 **寡妇级**——那年 M2 会战里坐过泰坦的人物，这晚刚一露脸先把黑隐留在了门前；随后十一点三十六分二十六秒，[昆仑](../../corps/kunlun/) 的澳区外交官 [虚实](../../p/2122263187/) 也把一条近十二亿的救世级留在了对手炮线下，隔了三分钟，挂在 Snuff [天降](../../corps/the-skies-descend/) 名下的 [少侠](../../p/2118354268/) 小号 `L-Isaac` 则交出一条奉献级重拦与蛋壳；倒是另一名在 Infinity Avenger 站台的 [汉堡](../../p/2117195144/) 驾驶狂暴级稳稳跟完了整局对轰。当然黑隐这行本来就是高风险买卖，FRT 阵营 `Arknights` 的创建人之一 [瓜瓜](../../p/2116478004/) 的小号也在十一点二十九分顺手赔掉了一艘十亿出头的寡妇级与蛋壳。
:::

## 百条泰坦开炮末日，六百五十三亿夜神倒在反击火海

如果说前五分钟还是两边黑隐与重拦在试探门道，那么当 FRT 把 **一百零二条泰坦与五十五条超级航母** 真正推上同一片视野的时候，MC6O-F 立刻变成了纯单边超旗武器（DD）的屠宰场——反观 INIT、帝国与 Snuff 阵线一整场连一条超级旗舰都没往下拍，只靠一百零八条常规无畏与五条战力辅助舰硬吃正面炮火。B 站后来传出一篇标题极其写实的视频《FRT泰坦出击！MC60 dd init无畏群 1N-复刻？》（作者还在简介里调侃自己“刚睡醒 操作太抠脚了 别喷别喷”），几乎道出了当时战场一边倒的恐怖压迫感。

在整整半个小时的密集末日齐射下，INIT 与友军的一百零八条无畏足足被砸沉了一百零三条——光普通神示级就倒了整整 **九十一条**，外加五条使徒级、三条莫洛级和三条航母！

::: 高潮 大聪明俄洛巴斯与冥府兜底段子，丝提西亚九十六杀连带夜神落水
平时 [大聪明](../../p/2116384303/) 这个 ID 总让群友先想起论坛段子和百科玩笑，可在 `MC6O-F` 的战报里，这位来自女娲的老哥一口气拿小号同时把 **俄洛巴斯级泰坦与冥府级超级航母** 两尊巨兽一起开进了核心阵地，用机库里最厚实的那两页资产亲自替自己的段子名声兜了底；同时间 [清水](../../p/2122271544/) 一手控拉格纳洛克级（直接末日劈死对面神示级拿到榜首）、一手控冥府级（轰出六十八亿使徒级最高伤害），[傅里叶](../../p/2121301474/) 开着 **万古级超航** 稳稳带队收掉对方神示榜首，[此方](../../p/2122857798/) 也双开阔刀级与拉格纳洛克级上阵。全战表现最夸张的莫过于 `Arknights`“一人小队” [丝提西亚](../../p/2115264327/)：四个账号同时压出 **两条勒维亚坦级与两条泽尼塔级**（加莫洛级海军型替换上场），狂砍 **九十六次击杀** 与五项对神示、莫洛和使徒级的最高伤害榜首，代价则是十一点二十九分和三十二分接连交掉六十亿莫洛级海军型与七十点三亿泽尼塔级。

偏偏就在百条泰坦呼风唤雨的十一点三十四分，不甘心白挨揍的 INIT 与 Snuff 残余火力抓准破绽狠狠咬了一口——FRT 一侧一艘估值高达 **六百五十三点三亿的夜神级超级航母** 顶不住集火轰然炸裂，加上守军自己三十九条折损无畏里的几位熟人（例如十一点二十九分交出七十二点四亿泽尼塔级后居然又在尾声开着 **囤积者货船** 进场再爆一趟的 [乔伊](../../p/2113281289/)，与十一点三十五分交出七十一点五亿凤凰级海军型外加 **十五点五亿太空舱** 的 [铁头](../../p/2117494997/)，以及同盟丢掉的小号奉献级的 [嗜血](../../p/2113483277/)），硬生生让这局本该十拿九稳的屠杀场也在自己账本上留出了几百亿血印。
:::

## 橘子围杀神示摘尾刀，二十年老冠军开大鱼横扫三百杀

除了百条泰坦一齐轰下的一波波大肉，在混乱的边角和旗舰堆缝隙里，还藏着两笔堪称整场最有画面感、事后最够拿回军团群吹半年的小账。

::: 高潮 橘子六人围杀神示摘尾刀，光头开大鱼刷满两百九十九杀
[采星者](../../corps/starchaser/) 的 [橘子](../../p/2114324589/) 这晚自己稳坐勒维亚坦级跟着超旗阵推进，同时还顺手办成了一笔最紧凑的小场奇袭：在一场只有 **六个人联手合围** INIT 神示级无畏舰的短兵相接里（KM `133727798`），那最后一下结结实实的尾刀恰好落在了橘子名下——扔进万亿级大账里不过是九十一分之一条神示，缩小到六人小组里却足够全队战后把这张击杀邮件翻来覆去夸上三遍。

而整张击杀榜里最魔幻的数据，直接属于从国服打到欧服的二十年冠军老号 [光头](../../p/855247117/)（EvilDobar）：这位平时拿战果当奖状墙的猛人，小号 `noarus` 开着莫洛级海军型老老实实狂刷一百零六杀、五夺敌船最高伤害还不算完，**主号居然亲自开着一艘工业旗舰大鱼级直接挤进了 `MC6O-F` 核心火海**，靠着满天无人机硬生生刷出惊世骇俗的 **两百九十九次参与击杀**，一路包揽整整 **十一项太空舱（最高一笔蛋壳高达三十一点三亿）与敌方狂暴级的最高伤害榜首**！别人开泰坦都未必凑得齐四百多条署名，他一条工业矿船加一条海军无畏直接把 `MC6O-F` 战表洗了一遍。
:::

常规护航线也同样没有只是站着看超旗开炮：[艾若](../../p/2116531837/) 一边拿主号开休津级贴脸挂网、一边把小号塞进神示级海军型收下狂暴伤害榜首，老炮 [叼爷](../../p/1387156123/) 驾着救世级在外圈刷满六十六杀，连一贯双开重火力的 [彗星](../../p/2121096598/) 也拉着两条死亡漩涡级跟进点射，刚刚拿完 AT 亚军的 [Hoshimati Comet](../../p/2120246500/) 同样混在队伍里亲自验了一回百条泰坦齐射的现场。

## 一小时出头烧穿万亿，同个华人圈各自签单散场

世界时十二点三十一分，全长仅仅六十八分钟的 `MC6O-F` 会战便在超旗绝对压制下提前落下帷幕。按网页实际分方与接口总账统计，FRT 及友军六百一十一人一共仅付出约 **三千九百五十五亿**（一百二十五条损失记录，含三十九条常规无畏与那艘孤零零的夜神级）；反观被泰坦当靶子集火、却硬生生换掉一条超航与几十条无畏的 INIT、帝国与 Snuff 三百七十二人，则共同扛走了将近 **七千四百六十九亿**（五百九十三条记录，逾九十条神示级排成了一整串）。

::: 高潮 刚睡醒的超旗与同桌熟人的两面账
散场之后再把片子与账本放到同一张桌面上，最扎眼的莫过于两件事：第一，前一晚还传过同日隔壁星系混战（`6RCQ-V`）的猜测很快被各自战报划清，真正留在 `MC6O-F` 正剧里的便是 FRT 这百条泰坦一口气按死 INIT 百条无畏的硬碰硬，连投稿玩家《又玩到泰坦了爽D了》都直接感叹这一场捞满战果；第二，在这样一个双方合计只剩不到千人、却烧穿 **一万一千四百一十七亿** 的高密战场里，华人老熟人偏偏分坐在两张一模一样的椅子上——一边有开泰坦超航的大聪明与丝提西亚，一边有刚跳出来迎面送出寡妇和救世的七喜、小洋、虚实、少侠与汉堡。
:::

::: 评
`MC6O-F` 证明了一件事：当一百多条泰坦真正落地贴脸的时候，哪怕对面拿出一百多条神示硬扛、还咬死了一艘六百五十三亿的夜神级，账本最后的倾斜方向依然没有任何悬念——只是在这样一台万亿规模的无畏粉碎机里面，照样挤得下六个人围杀无畏的尾刀小菜，也容得下一条大鱼工业舰靠着两百九十九杀抢尽泰坦风头的荒诞奇观。

同一个华人圈分坐红蓝两面旗帜之下，最后却全被记进同一份万亿战报。今天有人刚睡醒按下一炮末日，明天或许又在下一片星域和老邻居迎面碰上；船炸了找军团补，顺手写进简历里的那句“我在 MC6O 开过大鱼”，倒是能跟人吹上好几年。
:::
