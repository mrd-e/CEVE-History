本来只是一场低安星门边的战列遭遇战，三个小时滚完雪球，却让三百八十五位驾驶员烧出了两百六十三条残骸与逾七千零五十亿 ISK 的昂贵账单。在[伊瓦提](../../battles/evati-2025/)的下午战局里，FRT 及友军（两百四十一人、损约三千一百三十二亿）硬碰 `Dreadnought Diplomacy.`（DD）、`FL33T` 加上终盘赶到的深水（一百三十四人、损约三千九百亿）；场面上双方都在拼命往网格里填无畏舰，偏偏据事后 `BearThatCares` 在[红迪复盘](https://www.reddit.com/r/Eve/comments/1n54a6m/)与[完整战报](https://br.evetools.org/br/68b49c7a4ff6700012d911f2)揭出的实情——一边在前线高喊“再来一批无畏”，自家后台一边还在算错诱导距离、满世界给航母翻找燃料。

## 噩梦先与巴盖斯星门撞头，四开控场把遭遇战抬上大桌

下午十五时刚过，伊瓦提星门边的空气先被 `DD` 的 `噩梦级` 与 `FRT` 的 `巴盖斯级` 点燃。最初不过是低安常见的常规战列互试火力，可两边手头都攒着大批随时能点诱导的储备力量，冲突几乎没有犹豫就朝旗舰规模滑了过去。

::: 高潮 门房总监四开坐镇指挥位，老巡逻手刚好在家门口赶上大战
眼看常规线越缠越厚，[伏羲](../../corps/fuxi/) 那位平时靠审档案、拦小号出名的门房总监 [瞑衍](../../p/2118776119/) 干脆换上截然不同的口气，自己坐进舰队指挥位稳住进退节奏，顺手还同开着 **四个账号** 在混战周边拉扯（名下三个小号在混战里先后交出从几千万到二点五亿不等的船损）；[混沌](../../corps/chaos/) 团长 [星星](../../p/2114362964/) 则驾着 `永灭级` 在常规线替炮手们咬定目标方向，同队还有三开的 [小夹子](../../p/2119942097/)（交出两亿二船损兼太空舱）与 [伏羲](../../corps/fuxi/) 骨干 [杰克](../../p/2122861740/)（赔出一十二点四亿座舰）死咬正门。更有意思的是 [固执的细胞](../../p/2122323917/)——伊瓦提本来就是他日常单人低安巡逻清单里排第一的老地盘，这天正好撞见家门口摆开大会战，索性拎着轻船直接冲进人堆里赔掉五千万外加太空舱，顺便在家门口签上一笔大场面。
:::

## 后勤旗舰龙鸟先炸六十七亿半，老板亲自坐进神示级海军型端炮上桌

星门边的试探刚一升温，两边紧跟着便亮起后勤旗舰与无畏诱导。重装甲与高修量一铺上桌面，前线先交起第一笔沉重学费——连负责护航的常规战列与旗舰奶妈都成了第一时间重点清除的目标。

::: 高潮 龙鸟先沉六十余亿，SARD 老板离开指挥椅亲自打响神示级海军型
十五点四十分三十二秒，[行星之光](../../corps/lotm/) 的普通出勤者 [墨菲](../../p/2117806220/) 先行倒在 `DD` 集火之下，价值[一十二点三亿的巴盖斯级](https://zkillboard.com/kill/129568114/)连带着随后的 `惩罚者级` 与太空舱一起写进他的战场日记；紧接着只隔一分多钟，十五点四十一分四十九秒，[伏羲](../../corps/fuxi/) 那位自称“我不是猫猫人”的 UP 主 [云曦](../../p/2122641296/) 也看着小号座下的 `龙鸟级` 战力辅助舰在十三人围射中炸穿（[六十七点五亿](https://zkillboard.com/kill/129568145/)）。可旗舰后勤遇挫并没能吓住 FRT 无畏队：向来习惯在后方频道里喊人进场的 [SARD 特别执法部](../../corps/sard/) 老板 [嗜血](../../p/2113483277/)，这回干脆丢开老板椅亲自端炮上桌，开着一艘 `神示级海军型`（[KM 129569568](https://zkillboard.com/kill/129569568/)）一炮一炮往敌阵砸去；而 [神农](../../corps/shennong/) UP 主 [海氏袖笼](../../p/2122617868/) 也开出小号钻进这轮无畏火网，事后顺势交出[《EVE欧服 FRT 8.31低安无畏爽射局》](https://www.bilibili.com/video/BV1TkaLzQEFn/)，算把当天亲手开炮的热乎劲留成了影像。
:::

## 九十九亿凤凰级海军型正面换炮，前线拼命加码、对手后面满世界找油

进入十六时前后，这场低安对攻彻底打进了无畏排成行对轰的最凶时刻。对面 `DD` 与 `FL33T` 的旗舰接连挨打（其中一艘 `神示级海军型` 在十六点十六分零四秒炸出[一百零九点一亿](https://zkillboard.com/kill/129569253/)高位战损），可 FRT 的无畏前排同样得一口咬着牙挨过反击炮火。

::: 高潮 小麦交掉近百亿凤凰级海军型，BearThatCares 自嘲“后面在找油”
[伏羲](../../corps/fuxi/) 兼顾后台 IT 与地板后勤的 [小麦](../../p/2120434064/)，平时帮团队擦亮后勤系统，到无畏互拆时一样得拿自家仓库买单：十六点零四分五十秒，他驾着 `凤凰级海军型` 狠狠把火力拍向对手无畏（[KM 129568904](https://zkillboard.com/kill/129568904/)）；不到一分钟后的十六点零五分四十八秒，集火便砸回到他头上，当场送走那艘[**九十九亿的凤凰级海军型**](https://zkillboard.com/kill/129568926/)，外带一艘十二点二亿的[巴盖斯级](https://zkillboard.com/kill/129569348/)。好在另一侧的窘迫一点也没比这边体面多少：`FL33T` 的 `BearThatCares` 事后在红迪坦白得格外实诚，一边替敢往火海里继续填无畏的队友鼓掌，一边自曝己方诱导距离算岔、连赶来救场的航母燃料都没算够——“前线在加码，后面在找油”，油箱干着的增援再英勇，也点不亮起跳的那枚按钮。
:::

## 深水压轴进场却见一秒双杀，七千零五十亿伊瓦提在残骸里散场

末段时分，`Deepwater Hooligans`（深水）带着新一批增援杀入伊瓦提接应 `DD` 与 `FL33T`（`BearThatCares` 复盘里还提到尾声另有 `Snuff` 的诱导闪现，而少量未归属零散角色不足十人、共十余亿战损），战局随即在高位消耗下步入撤离收尾。三小时结账，FRT 一方以近二百五十号人烧掉约三千一百三十二亿，迎敌的 `DD`、`FL33T` 与深水联军虽人数少上近半，总战损却直奔 **三千九百亿**。

::: 高潮 同社区好手站在对面，汉堡双开娜迦一秒内接连爆掉
少有人在战报首页留心到的是，这一天站在深水[黑曜军械](../../corps/obsidian-armament/) 旗帜下正面对狙 FRT 的名单里，还站着两位华人圈熟客——[漆黑](../../p/2121165138/) 与双开上场的 [汉堡](../../p/2117195144/)。偏偏临到十六时半收官前，[汉堡](../../p/2117195144/) 手里两台并排输出火力的 `娜迦级` 战列巡洋舰一起被抓了个正着，先是小号在十六点三十四分四十七秒爆出[一点九亿亏损](https://zkillboard.com/kill/129569728/)，紧隔**仅仅一秒**，主号就在十六点三十四分四十八秒紧跟着交代在同一波火力下（[二点一亿](https://zkillboard.com/kill/129569731/)兼太空舱）。随着 [娃娃](../../p/96548383/)、[石头](../../p/2121840947/) 与 [此方](../../p/2122857798/) 等老面孔在尾声里收炮撤回星门，这场从星门小擦枪烧成无畏换血的下午对局就此收尾，既成了 `Ph33rfactor` 与 `海氏袖笼` 镜头里的爽射局，也让“前线加码、后台找油”变成了低安后勤最实在的笑谈。
:::

::: 评
伊瓦提的教训其实一点不玄妙：指挥肯压胆子、团长肯自己端炮上无畏固然重要，可真到了星门遭遇演变成三小时旗舰对赌时，最后能不能顺利跳回安全屋，还得低头看看诱导坐标算没算错、航母油箱里还有没有油。前两样能写进最燃的战后集锦，最后一样却专门负责把热血动员变成红迪置顶里的全服段子。
:::
